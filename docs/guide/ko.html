WiFi 전송

로컬 네트워크의 모든 기기에서 책을 업로드하세요.

📶 작동 방식

앱이 기기에서 소형 웹 서버를 실행합니다. 같은 WiFi 네트워크의 모든 컴퓨터나 휴대폰이 브라우저에서 업로드 페이지를 열 수 있습니다.

  1. 설정 → 책 가져오기 → WiFi 전송으로 이동합니다.
  2. 서버 시작을 탭합니다. http://192.168.1.42:8080과 같은 주소가 나타납니다.
  3. 같은 네트워크의 웹 브라우저에서 해당 주소를 엽니다.
  4. 파일을 페이지에 드래그하거나 클릭하여 선택합니다 — 원하는 경우 대상 폴더를 선택하세요.
  5. 가져온 책이 즉시 라이브러리에 나타납니다.
  6. 완료되면 서버 중지를 탭합니다.
팁: 서버가 실행되는 동안 기기가 절전 모드로 전환되지 않아 전송이 중단되지 않습니다.
업로드 실패? 실패한 각 파일은 해당 행에 사유가 표시됩니다. WiFi 연결이 끊긴 경우, 해당 행의 ↻ 재시도를 탭하여 다시 전송하세요. 지원되지 않는 파일 형식과 같은 영구적인 문제에는 재시도 버튼이 표시되지 않습니다.

라이브러리 및 정리

책을 검색하고, 정렬하고, 정리하세요.

🔍 검색

라이브러리 하단의 Search 필을 탭하여 검색 필드를 펼친 다음, 완료를 탭하여 닫습니다. 제목, 저자, 태그, 시리즈, 출판사, 설명을 통해 검색합니다. 책의 컨텍스트 메뉴에서 저자나 태그로 검색하면(저자 및 태그별 찾아보기 참조) 동일한 검색이 채워집니다.

↕ 정렬 및 필터

보기 옵션 버튼(오른쪽 상단)을 탭하여 선택하세요:

  • 레이아웃 — 그리드, 상세, 컴팩트, 미니멀, 테이블 또는 매거진
  • 정렬 — 제목, 저자, 마지막 읽은 날짜, 추가 날짜, 진행률, 파일 크기, 시리즈
  • 표시 — 읽고 있는 책을 먼저, 완독한 책을 마지막에 배치
  • 필터 — 형식, 태그 또는 저자별

✔ 선택 모드

책을 길게 누르거나 선택을 탭하여 선택 모드로 진입합니다. 여러 책을 한 번에 이동, 삭제, 숨기기 또는 숨기기 해제할 수 있습니다.

📋 중복 항목 정리

제목, 저자, 형식이 같은 책을 찾으려면 설정 > 라이브러리 > 라이브러리 유지 관리 > 중복 항목 정리로 이동하세요. 각 중복 그룹에 대해:

  • 최신 버전에는 녹색 KEEP 배지가 표시됩니다
  • 체크박스로 이전 사본을 선택하세요 (또는 모두 선택)
  • 삭제 — 선택한 이전 사본을 제거합니다
  • 데이터 복사 후 삭제 — 삭제하기 전에 책갈피, 하이라이트, 태그, 읽기 진행도, 책장 배정을 최신 버전으로 옮깁니다
  • "새 책을 옛 책의 책장 및 숨김 상태로 이동"을 활성화하면 새 버전을 라이브러리의 동일한 위치에 유지할 수 있습니다

서가 및 폴더

중첩 폴더로 책을 정리하세요.

📂 서가 만들기

  1. 라이브러리 상단에서 새 서가를 탭합니다.
  2. 이름을 입력하고 아이콘과 색상을 선택합니다.
  3. 하위 폴더를 만들려면 상위 서가를 선택합니다(선택 사항).

⇄ 책 이동

책의 상세 페이지에서 메뉴(…)를 탭하고 서가로 이동을 선택합니다. 선택 모드에서는 여러 책을 한 번에 이동할 수 있습니다.

↑ 맨 위로

책 읽기

EPUB, PDF, TXT, RTF 읽기 모드.

📖 EPUB

EPUB은 완전한 기능을 갖춘 리더에서 열립니다. 왼쪽 또는 오른쪽 가장자리를 탭하거나 스와이프하여 페이지를 넘기세요.

  • 페이지 넘기기 — 전통적인 한 페이지씩 읽기 — 슬라이드, 넘기기, 또는 애니메이션 없음 중에서 선택할 수 있습니다.
  • 연속 스크롤Premium — 페이지 구분 없이 자연스럽게 스크롤.
  • 읽기 방향 — 책을 자동으로 따르거나, 왼쪽에서 오른쪽 또는 오른쪽에서 왼쪽으로 직접 설정하세요. 자세한 내용은 읽기 방향을 참고하세요.
  • 고정 레이아웃 — 만화, 그림책 등 페이지 단위로 구성된 EPUB은 전용으로 만들어진 리더에서 열립니다. 자세한 내용은 고정 레이아웃 책을 참고하세요.
  • 책 내 검색Premium — 책 전체에서 원하는 단어나 문구를 검색하세요. 자세한 내용은 책 내 검색을 참고하세요.
  • 이미지 갤러리Premium — 책의 상세 페이지에서 EPUB의 모든 이미지를 둘러보세요. 자세한 내용은 이미지 갤러리를 참고하세요.
팁: 설정 → 읽기 환경설정 → 책에서 글꼴 크기, 줄 간격, 테마 색상을 조정하세요.

📄 PDF

PDF는 기본적으로 렌더링됩니다. 핀치하여 확대/축소하고 스와이프하여 페이지를 넘기세요. 앱이 보호된 PDF의 비밀번호를 기억할 수 있습니다.

📝 TXT 및 RTF

일반 텍스트 및 RTF 파일은 서식을 조정할 수 있는 간단한 텍스트 리더에서 열립니다.

↑ 맨 위로

고정 레이아웃 책

페이지가 고정된 디자인으로 이루어진 EPUB — 만화, 그림책, 삽화가 많은 도서.

📐 무엇인가요

일부 EPUB은 흐르는 텍스트가 아니라 페이지 단위로 구성되어 있습니다. 모든 페이지가 글과 그림이 고정된 배치로 이루어져 있는 것입니다. 앱은 이런 책을 자동으로 인식하여 전용으로 만들어진 리더에서 엽니다 — 각 페이지는 화면에 맞게 크기가 조정되어 가운데 정렬되며, 주변 여백은 읽기 테마의 배경색으로 채워집니다.

👋 읽기 및 확대

  • 화면의 왼쪽 또는 오른쪽을 탭하거나 스와이프하여 페이지를 넘기세요. 가운데를 탭하면 도구 모음이 표시되거나 숨겨집니다.
  • 핀치하여 확대하세요 — 맞춤 크기의 최대 3배까지 — 그리고 드래그하여 페이지를 이동하세요.
  • 두 번 탭하면 해당 위치가 확대되고, 다시 두 번 탭하면 페이지가 화면에 맞게 축소됩니다.
  • 오른쪽에서 왼쪽으로 읽도록 출판된 책은 자동으로 그 방향으로 페이지가 넘어갑니다.

📖 두 페이지 스프레드

기기를 가로 방향으로 돌리면 마주보는 페이지가 나란히 표시됩니다. 앱은 책 안에 포함된 스프레드 힌트를 따르므로, 표지나 전면 삽화는 여전히 한 페이지를 단독으로 차지합니다. 세로 방향으로 되돌리면 한 번에 한 페이지씩 표시됩니다.

ℹ 사용 가능한 기능

목차, 북마크, 진행률 슬라이더, 읽기 기록, 이어서 읽기는 모두 평소처럼 작동합니다.

각 페이지가 앱이 재배치할 수 있는 텍스트가 아니라 고정된 디자인이기 때문에, 이런 책에서는 일부 기능이 나타나지 않습니다: 연속 스크롤 및 자동 스크롤, 글꼴 및 화면 설정, 텍스트 음성 변환, 책 내 검색, 텍스트 선택 및 하이라이트.

책 내 검색

읽고 있는 책 안에서 원하는 단어나 문구를 찾으세요.Premium

🔍 검색 시작하기

  1. 페이지 중앙을 탭하여 도구 모음을 표시하세요.
  2. 하단 바의 오른쪽 끝에 있는 돋보기를 탭하세요.
  3. 두 글자 이상 입력한 다음 키보드에서 검색을 누르세요.

화면에 보이는 챕터만이 아니라 책 전체 — 모든 챕터 — 가 검색되며, 대소문자는 구분하지 않습니다. 검색은 EPUB 및 TXT/RTF 리더에서 사용할 수 있습니다.

📄 결과 살펴보기

결과는 검색 바 아래에 챕터별로 묶여 표시됩니다. 각 행에는 주변 텍스트의 일부와 함께 일치 항목이 굵게 표시됩니다. 결과를 탭하면 해당 위치로 바로 이동합니다 — 책 안의 모든 일치 항목이 노란색으로 하이라이트되고, 현재 항목은 더 진한 호박색으로 표시됩니다.

↕ 일치 항목 간 이동

결과를 하나 선택하면 검색 바가 간결한 스트립으로 접히고, 전체 일치 항목 중 현재 위치를 보여주는 카운터가 표시됩니다.

  • 위/아래 화살표로 이전 또는 다음 일치 항목으로 이동하세요.
  • 목록 버튼을 탭하면 전체 결과 목록이 다시 열립니다.
  • ×를 탭하면 검색이 종료되고 모든 하이라이트가 제거됩니다.

이미지 갤러리

EPUB의 모든 삽화를 스와이프 가능한 갤러리로 둘러보세요.Premium

🖼 갤러리 열기

EPUB 책의 상세 페이지를 열고 오른쪽 위 도구 모음의 사진 스택 버튼 🖼을 탭하세요. 앱이 책에서 모든 이미지를 추출하며, 작업하는 동안 진행률 바가 표시됩니다 — 왼쪽 위의 × 버튼을 탭하면 언제든지 빠져나올 수 있습니다. 갤러리는 EPUB 책에서만 사용할 수 있습니다.

📚 표시되는 내용

이미지는 표지를 포함하여 읽기 순서 — 책의 챕터에 등장하는 순서 — 대로 한 페이지에 하나씩 표시됩니다. 아이콘이나 장식 같은 아주 작은 이미지는 건너뜁니다. 최소 크기(기본값 100 px)보다 작은 것은 제외됩니다. 임계값은 설정 → 읽기 환경설정 → 책 → EPUB 갤러리에서 조정하세요. 조건에 맞는 이미지가 없으면, 찾은 이미지가 없다고 갤러리에 표시됩니다.

👆 이미지 보기 및 저장

  • 스와이프하여 이미지 간을 이동하거나, 하단의 페이지 슬라이더로 빠르게 이동하세요.
  • 핀치하거나 두 번 탭하여 확대한 다음, 드래그하여 이동하세요 — 갤러리는 만화 리더를 사용하므로 확대 방식도 완전히 동일합니다. 자세한 내용은 만화 페이지 확대를 참고하세요.
  • 화면 중앙을 탭하면 컨트롤이 표시되거나 숨겨집니다.
  • 이미지를 길게 누르면 전체 해상도 보기 — 더 자세히 보기 위해 원본 크기로 여는 기능 — 를 사용하거나, 사진 앱에 저장, 파일 앱에 저장, 이미지 복사를 사용할 수 있습니다.
  • 갤러리는 만화 읽기 방향을 따릅니다 — Webtoon 스타일의 세로 스크롤도 포함됩니다.

읽기 글꼴

읽기 글꼴을 선택하고, 직접 추가하거나, 언어 팩을 다운로드하세요.

🔤 글꼴 선택

설정 → 읽기 환경설정 → 책 → 사용자 지정 글꼴을 열면 글꼴 화면으로 이동합니다. 여러 읽기 글꼴이 기본 제공되며, Literata가 기본값입니다. 선택한 글꼴은 EPUB 및 텍스트 리더에 적용됩니다.

팁: 설정 → 읽기 환경설정 → 책에서 글꼴 크기와 줄 간격을 조정하세요.

👓 접근성 글꼴

더 쉬운 읽기를 위해 설계된 두 가지 글꼴이 기본 포함되어 항상 사용할 수 있습니다. 비슷한 글자 간의 차이를 뚜렷하게 하는 Atkinson Hyperlegible과, 글자 혼동을 줄이도록 아래쪽에 무게를 둔 OpenDyslexic입니다.

📂 사용자 지정 글꼴

글꼴 화면에서 직접 준비한 .ttf 또는 .otf 글꼴 파일을 가져와 EPUB 리더에서 사용하세요. 가져온 글꼴은 기기에 저장됩니다.

📥 글꼴 및 언어 팩 다운로드

글꼴 다운로드에서는 앱에 기본 포함되지 않은 문자 체계를 위한 추가 읽기 글꼴과 언어 팩을 필요할 때 받을 수 있습니다 — 중국어, 일본어 및 한국어(CJK), 아랍어, 데바나가리, 태국어. 팩은 용량이 크므로(각각 약 41 MB) 다운로드 전에 크기가 표시됩니다. 설치하면 가져온 글꼴과 똑같이 작동합니다.

팁: 책의 문자가 빈 네모로 표시되면, 해당 언어 팩을 다운로드하여 표시하세요.

📜 글꼴 라이선스

읽기 방향

왼쪽에서 오른쪽, 오른쪽에서 왼쪽, 또는 책이 출판된 방향 그대로.

⇄ 방향 선택하기

설정 → 읽기 환경설정 → 책을 열고 읽기 모드 아래의 읽기 방향 컨트롤을 사용하세요:

  • 자동(기본값) — 책 자체가 지정한 방향을 따릅니다. 만화와 오른쪽에서 왼쪽으로 읽도록 출판된 책은 별도 설정 없이 올바른 방향으로 열립니다.
  • 왼쪽에서 오른쪽으로 — 대부분의 서양 도서에 대한 표준입니다.
  • 오른쪽에서 왼쪽으로 — 모든 책에 오른쪽에서 왼쪽 방향을 사용합니다.

책을 나가지 않고도 변경할 수 있습니다: 페이지 중앙을 탭하여 도구 모음을 표시한 다음, 하단 바의 Aa 버튼을 탭하세요. 변경 사항은 현재 읽고 있는 페이지에 즉시 적용됩니다.

👋 방향을 따르는 요소

  • 다음 페이지로 넘어가는 방향 — 오른쪽에서 왼쪽으로 읽는 책에서는 왼쪽으로 탭하거나 스와이프하면 다음 페이지로 넘어갑니다.
  • 올바른 쪽에서 넘어가는 페이지 넘김 애니메이션.
  • 페이지 안 텍스트의 배치.
참고: 진행률 슬라이더는 항상 왼쪽부터 채워집니다. 화면상의 페이지 위치가 아니라 책을 얼마나 읽었는지를 보여주기 때문입니다.

ℹ 적용 범위

이 설정은 페이지 넘김 모드의 EPUB에 적용됩니다 — 연속 스크롤이 켜져 있으면 숨겨집니다. 만화는 자체적인 읽기 순서 설정을 사용하며(만화 읽기 참고), 고정 레이아웃 책은 항상 책에 지정된 방향을 따릅니다.

세로쓰기

세로 단으로 조판된 일본어 및 중국어 도서.

⬇ 세로쓰기 책

세로로 조판된 책 — 일본어 다테가키(縦書き)와 중국어 정체 세로쓰기(直排) — 는 원래 조판된 방식 그대로 표시됩니다. 텍스트는 위에서 아래로 흐르는 단이 오른쪽에서 왼쪽으로 채워지며, 만화와 마찬가지로 페이지는 왼쪽으로 넘어갑니다.

⚙ 쓰기 방향

설정 → 읽기 환경설정 → 책을 열고 쓰기 방향 컨트롤을 사용하세요:

  • 자동(기본값) — 각 책의 고유한 레이아웃을 따릅니다. 세로로 조판된 책은 세로로 표시되며, 다른 모든 책은 영향을 받지 않습니다.
  • 가로쓰기 — 세로로 조판된 책을 포함해 모든 책을 가로로 배치합니다.
  • 세로쓰기 — 모든 책을 세로 단으로 배치합니다.

같은 컨트롤은 리더 내 설정의 Aa 버튼 아래에도 있습니다.

참고: 변경 사항은 다음에 책을 열 때 적용됩니다 — 현재 화면에 열려 있는 책은 열렸을 때의 레이아웃을 유지합니다.

ℹ 알아두면 좋은 점

  • 세로쓰기 책은 항상 페이지 넘김 모드를 사용하므로 연속 스크롤과 자동 스크롤을 사용할 수 없습니다.
  • 세로쓰기 책에는 슬라이드 페이지 애니메이션이 사용되지 않습니다 — 대신 넘기기 애니메이션으로 넘어갑니다.
  • 북마크, 하이라이트, 목차, 책 내 검색, 텍스트 음성 변환은 모두 평소처럼 작동합니다.

만화 읽기

CBZ, CBR, CB7 만화 읽기.

📱 읽기 모드

  • 왼쪽에서 오른쪽 — 표준 서양 만화 페이지 순서.
  • 오른쪽에서 왼쪽 — 만화(망가) 읽기 순서.
  • Webtoon / 세로 스크롤 — 긴 스트립 만화를 위한 부드러운 세로 스크롤.

설정 → 읽기 환경설정 → 만화에서 전역 기본값을 설정하거나, 각 책의 상세 페이지에서 개별 설정할 수 있습니다.

🔎 페이지 크기 조절

  • 화면에 맞추기 — 전체 페이지가 보입니다.
  • 너비에 맞추기 — 너비를 채우고, 필요 시 세로로 스크롤합니다.
  • 높이에 맞추기 — 높이를 채웁니다.
  • 원본 크기 — 1:1 픽셀 표시.

👋 제스처

  • 좌우로 스와이프하여 페이지를 넘깁니다(페이지 넘기기 모드).
  • 핀치하거나 두 번 탭하여 확대한 다음, 드래그하여 이동하세요. 자세한 내용은 만화 페이지 확대를 참고하세요.
  • 페이지 중앙을 탭하여 도구 모음을 표시하거나 숨깁니다.
  • 하단의 페이지 슬라이더를 사용하여 빠르게 이동합니다.

⚠ 의심스러운 아카이브 경고

만화 아카이브(CBZ, CBR 또는 CB7)를 열었을 때 그 내용이 비정상적으로 크거나 과도하게 압축되어 있다면 — 메모리를 과부하시키도록 설계된 “zip bomb” 파일에서 사용되는 패턴 — 앱은 압축을 해제하기 전에 의심스러운 아카이브 경고를 표시합니다.

  • 파일을 열지 않으려면 취소를 탭하세요. 출처를 알 수 없는 아카이브에는 이 옵션이 안전한 선택입니다.
  • 파일을 신뢰한다면 그대로 열기를 탭하세요 — 앱은 안전 검사를 건너뛰고 페이지를 로드합니다.

EPUB 파일도 가져오기 시 동일한 보호 기능을 자동으로 사용합니다.

만화 페이지 확대

페이지 모드와 웹툰 스크롤 모두에서 그림을 더 가까이 보세요.

🔍 페이지 모드

  • 핀치하여 확대하세요, 맞춤 크기의 최대 3배까지. 핀치하는 동안 그림이 손가락 아래 그대로 머뭅니다.
  • 두 번 탭하면 해당 위치가 2배 크기로 확대되고, 다시 두 번 탭하면 페이지가 화면에 맞게 축소됩니다.
  • 확대된 상태에서 한 손가락으로 드래그하면 이동할 수 있습니다.
  • 거의 원래 크기까지 핀치로 축소하면 페이지가 자동으로 맞춤 크기에 맞춰집니다.

확대는 화면에 맞추기 및 높이에 맞추기 크기 조절 옵션과 두 페이지 스프레드에서 작동합니다. 너비에 맞추기와 원본 크기는 이미 화면보다 크게 페이지를 표시하고 대신 스크롤하므로, 더 자세히 보려면 아래의 전체 해상도 보기를 사용하세요.

📱 Webtoon 스크롤

  • 핀치하거나 두 번 탭하면 전체 스트립이 최대 3배까지 확대됩니다.
  • 확대된 상태에서도 스크롤은 계속 작동합니다 — 평소처럼 위아래로 드래그하면 됩니다.
  • 좌우로 드래그하면 확대된 페이지 안에서 이동할 수 있습니다.
  • 스크롤을 계속해도 확대 수준이 유지되므로 챕터 전체를 확대된 상태로 읽을 수 있습니다. 기기를 회전하면 원래 크기로 돌아갑니다.

✨ 전체 해상도 보기

확대는 화면에 맞게 준비된 크기의 페이지를 크게 보여줍니다. 한 페이지를 최대한 선명하게 보려면 길게 눌러 전체 해상도 보기를 선택하세요 — 해당 페이지가 아카이브의 원본 해상도로 디코딩되어 훨씬 더 확대할 수 있습니다. 두 번 탭하면 화면 맞춤과 2배 크기 사이를 전환하며, 아래로 스와이프하거나 닫기 버튼을 탭하면 돌아갑니다.

참고: 확대 상태는 저장되지 않습니다. 책을 닫으면 항상 일반 맞춤 크기로 돌아갑니다.

🔊 텍스트 음성 변환 사용

EPUB, PDF 또는 TXT 책을 열고 도구 모음의 재생 버튼을 탭하세요. TTS는 한 문장씩 읽으며 현재 단어를 하이라이트합니다.

  • 속도 — TTS 컨트롤에서 0.5배속에서 2배속까지.
  • 음성 — 설정 → 읽기 환경설정 → 텍스트 음성 변환에서 100개 이상의 시스템 음성 중 선택.
  • 건너뛰기 — 다음/이전을 탭하여 문장 또는 챕터 단위로 이동.
참고: 고정 레이아웃 책 — 페이지가 고정된 디자인으로 이루어진 만화와 그림책 — 은 앱이 소리 내어 읽을 텍스트가 없으므로 재생 버튼이 표시되지 않습니다.

🚗 CarPlay

CarPlay 호환 차량에 연결하면 간소화된 재생 컨트롤과 함께 자동차 디스플레이에 앱이 나타납니다. TTS가 백그라운드에서 계속 재생되므로 화면을 켜 둘 필요가 없습니다.

팁: TTS 설정에서 백그라운드 오디오Premium를 활성화하면 CarPlay 없이도 앱이 백그라운드에 있을 때 재생을 계속할 수 있습니다.

AI 만화 업스케일링

기기에서 저해상도 만화 페이지를 향상시킵니다.Premium

✨ 기능 설명

기기의 머신 러닝 모델을 사용하여 해상도 기준치 이하인 만화 페이지를 업스케일합니다. 더 선명한 선과 줄어든 압축 아티팩트를 얻을 수 있으며, 오래되거나 저품질 스캔에 특히 유용합니다.

⚙ 설정

팁: 업스케일된 페이지에 작은 표시 배지가 나타납니다. 원하지 않으면 설정에서 끌 수 있습니다.

🔓 숨겨진 책 보기

🔒 개인정보 보호 옵션

숨김 모드가 활성화된 상태에서 설정 → 숨김 모드로 이동하여 앱을 나갈 때 동작을 선택하세요:

↩ 책 숨기기 해제

숨김 모드에서 숨겨진 책의 상세 페이지를 열고 책 숨기기 해제를 선택하거나, 선택 모드를 사용하여 대량으로 숨기기 해제하세요.

☁ 숨겨진 책 동기화

숨김 모드에서 설정 → 숨김 모드로 이동하여 숨겨진 책을 iCloud와 동기화를 켜세요:

  • 끔(기본값) — 숨겨진 책은 이 기기에만 유지됩니다. 책을 숨기면 iCloud에서도 제거됩니다.
  • 켬 — 숨겨진 책이 iCloud를 통해 동기화되지만 로그인한 모든 기기에서 계속 숨겨져 있습니다.

이미 iCloud에 숨겨진 책이 있는 상태에서 토글을 끄면 처리 방법을 묻습니다:

  • 모든 기기에 유지 — 다른 기기는 동기화된 사본을 유지하고, 이 기기는 로컬 전용 개인 사본을 유지합니다.
  • iCloud에서 완전히 삭제 — iCloud에서 책을 제거하며, 다른 각 기기는 숨겨진 라이브러리에 자체 개인 사본을 유지합니다.
참고: 다른 기기 중 하나가 iCloud에서 숨겨진 책을 제거하면, 이 기기는 책 파일이 이미 다운로드되어 있었던 경우 숨겨진 라이브러리에 자체 개인 사본을 자동으로 유지합니다.

🗑 숨겨진 책 영구 삭제

숨김 모드에서 설정 → 숨김 모드로 이동하여 숨겨진 책 영구 삭제를 선택하면 이 기기, iCloud, 다른 기기에서 모든 숨겨진 책이 제거됩니다. 확인하려면 DELETE를 입력하세요.

경고: 이 작업은 되돌릴 수 없습니다. 그 시점에 오프라인 상태인 기기는 다음 동기화 전까지 로컬 사본을 유지합니다.

북마크, 하이라이트 및 태그

🔖 북마크

리더 도구 모음의 북마크 아이콘을 탭하여 현재 페이지를 북마크합니다. 선택적으로 메모를 추가하세요. 책의 모든 북마크는 상세 페이지에서 확인할 수 있습니다.

참고: 여기에는 직접 만든 북마크만 표시됩니다. 책을 닫을 때 앱이 자동으로 저장하는 위치는 사용자가 의도적으로 추가한 북마크를 가리지 않도록 읽기 기록에 별도로 보관됩니다.

🖍 하이라이트Premium

EPUB에서 텍스트를 선택하여 하이라이트합니다. 5가지 색상(노랑, 분홍, 초록, 파랑, 주황) 중 선택하고 메모를 추가하세요. 모든 하이라이트는 책의 상세 페이지에 나열됩니다.

🏷 태그

책의 상세 페이지에서 태그를 추가하세요. 태그는 검색 가능하며 라이브러리 필터로 사용할 수 있습니다. 모든 태그는 설정 → 태그에서 관리하세요.

↑ 맨 위로

읽기 기록

최근에 머물렀던 위치로 바로 돌아가세요.

🕒 자동 저장

책을 닫거나 앱을 백그라운드로 보낼 때마다 현재 위치가 기록 항목으로 저장됩니다 — 북마크를 잊지 않아도 됩니다. EPUB, PDF, TXT/RTF, 만화 등 모든 리더에서 작동합니다.

  • 책마다 최대 50개의 최근 위치가 보관됩니다. 새 항목이 추가되면 오래된 항목은 자동으로 삭제됩니다.
  • 몇 분 안에 같은 위치에서 책을 다시 닫으면 중복을 만들지 않고 기존 항목이 업데이트됩니다.
  • 자동으로 저장된 위치는 의도적으로 추가한 북마크와 섞이지 않도록 수동 북마크 목록과 별도로 보관됩니다.

📖 책 안의 기록

책을 읽는 중 오른쪽 상단의 더보기 메뉴(…)를 탭하고 읽기 기록을 선택하세요. 해당 책의 최근 위치 목록이 최신 순으로 표시되며, 챕터 또는 페이지 이름과 각 항목이 기록된 시점이 함께 나옵니다.

  • 항목을 탭하면 해당 위치로 바로 이동합니다.
  • 항목을 왼쪽으로 스와이프하면 삭제됩니다.

📚 라이브러리 전체 기록

라이브러리 상단 도구 모음의 더보기 메뉴(…)를 탭하고 읽기 기록을 선택하면 최근에 연 모든 책을 날짜별로 묶어서 볼 수 있습니다. 행을 탭하면 멈췄던 위치에서 책이 바로 열립니다.

저자 및 태그별 찾아보기

앱 어디에서나 저자나 태그로 책을 찾아보세요.

👤 저자

설정 → 저자로 이동하면 라이브러리에 있는 모든 저자를 책 수와 함께 볼 수 있습니다. 저자를 탭하면 해당 저자의 모든 책을 라이브러리에서 검색합니다.

🏷 태그 검색

설정 → 태그에서 태그를 탭하면 그 태그가 붙은 책을 라이브러리에서 검색합니다. 길게 누르면 이름을 바꾸거나 삭제할 수 있습니다.

🔍 상황에 맞는 빠른 검색

  • 라이브러리에서 책을 길게 누르기 → [저자]의 책 찾기
  • 책의 상세 페이지에서 저자 이름이나 태그를 길게 누르면 검색됩니다

메타데이터 및 ComicInfo.xml

책의 메타데이터를 보고 편집하세요.

✏ 메타데이터 편집기

책의 상세 페이지에서 메뉴(…)를 탭하고 메타데이터 편집을 선택하면 제목, 저자, 시리즈, 설명 등의 항목을 변경할 수 있습니다. 원본 파일에서 메타데이터를 다시 추출할 수도 있습니다.

📋 ComicInfo.xml

ComicInfo.xml 파일이 들어 있는 만화 아카이브(CBZ, CBR, CB7)는 가져올 때 메타데이터가 자동으로 추출됩니다 — 제목, 작가, 시리즈, 화 번호, 줄거리, 출판사, 장르, 태그가 포함됩니다.

iCloud 동기화

기기 간에 라이브러리를 동기화하세요.

☁ 동기화 활성화

  1. 설정 → iCloud 동기화로 이동합니다.
  2. 라이브러리를 iCloud와 동기화를 켭니다.
  3. 동기화는 다음 앱 실행 시 적용됩니다.

메타데이터, 읽기 진행률, 북마크, 하이라이트, 서가가 같은 iCloud 계정에 로그인된 모든 기기에서 동기화됩니다.

📊 동기화 상태

설정 → iCloud 동기화에서 책 파일에 대한 상태 카드를 확인할 수 있습니다:

  • 헤드라인 — 최신 상태, 동기화 중…(개수 포함), 또는 로그인되지 않음.
  • 라이브러리 파일 중 얼마나 많은 부분이 iCloud에 있는지 보여주는 막대.
  • 세부 정보 — 동기화됨(전체 크기 포함), iCloud에만 있음(아직 이 기기에 다운로드되지 않음), 진행 중.
참고: 이 카드는 책 파일만 추적합니다. 읽기 진행률, 북마크, 하이라이트, 서가는 파일 상태와 관계없이 별도로 자동 동기화됩니다.

☁ 표지 배지

책 표지 오른쪽 아래 모서리에 파일 동기화 상태를 나타내는 작은 구름 아이콘이 표시됩니다:

  • 구름 아이콘 — 파일이 iCloud에만 있습니다. 책 페이지를 열어 다운로드하세요.
  • 위/아래 화살표 — 파일이 현재 업로드 또는 다운로드 중입니다.
  • 아이콘 없음 — 파일이 이미 이 기기에 있습니다.

📥 자동 다운로드

자동 다운로드의 최대 파일 크기를 선택하세요. 더 큰 책은 열 때까지 클라우드에 유지됩니다. iCloud 설정에서 제한을 조정하세요.

📊 독서 활동

WebDAV 및 OPDS

원격 서버와 카탈로그에서 탐색하고 다운로드하세요.

🗄 WebDAV

NAS, Nextcloud 또는 Calibre 서버에 연결하여 폴더를 탐색하고 책을 다운로드하세요.

  1. 설정 → 책 가져오기 → WebDAV로 이동합니다.
  2. 서버 추가를 탭하고 URL을 입력합니다.
  3. 필요한 경우 사용자 이름과 비밀번호를 추가합니다.
  4. 연결 테스트를 탭한 다음 저장합니다.
자체 서명 인증서: 서버가 자체 서명 인증서를 사용하는 경우 신뢰할 수 없는 인증서 허용을 켤 수 있습니다. 앱이 먼저 확인을 요청합니다 — 이 옵션은 TLS 검증을 비활성화하므로 같은 네트워크에 있는 누군가가 서버를 사칭할 수 있습니다. 직접 관리하는 서버에서만 켜세요.

📚 OPDS 카탈로그

OPDS는 도서 카탈로그를 위한 개방형 표준입니다. 공개 카탈로그(Project Gutenberg, Standard Ebooks 등) 또는 자체 개인 서버를 추가하세요.

  1. 설정 → 책 가져오기 → OPDS로 이동합니다.
  2. 카탈로그 추가를 탭하고 피드 URL을 입력합니다.
  3. 카테고리를 탐색하고 라이브러리에 책을 다운로드합니다.
