Transfer WiFi

Unggah buku dari perangkat apa pun di jaringan lokal Anda.

📶 Cara Kerjanya

Aplikasi menjalankan server web kecil di perangkat Anda. Komputer atau ponsel mana pun di jaringan WiFi yang sama dapat membuka halaman unggah di browser.

  1. Buka Pengaturan → Impor Buku → Transfer WiFi.
  2. Ketuk Mulai Server. Alamat seperti http://192.168.1.42:8080 akan muncul.
  3. Buka alamat tersebut di browser web mana pun di jaringan yang sama.
  4. Seret file ke halaman atau klik untuk menelusuri — pilih folder tujuan jika Anda mau.
  5. Buku yang diimpor langsung muncul di perpustakaan Anda.
  6. Ketuk Hentikan Server setelah selesai.
Tips: Perangkat Anda akan tetap terjaga selama server berjalan agar transfer tidak terputus.
Unggahan gagal? Setiap file yang gagal menampilkan alasannya langsung pada barisnya. Jika koneksi WiFi terputus, ketuk ↻ Coba Lagi pada baris tersebut untuk mengirimnya kembali. Masalah permanen (seperti format file yang tidak didukung) tidak akan menampilkan tombol Coba Lagi.

Perpustakaan & Organisasi

Temukan, urutkan, dan atur buku Anda.

🔍 Pencarian

Ketuk pil Search di bagian bawah perpustakaan untuk membuka kolom pencarian, lalu ketuk Selesai untuk menutupnya. Pencarian mencakup judul, penulis, tag, seri, penerbit, dan deskripsi. Mencari berdasarkan penulis atau tag dari menu konteks buku (lihat Jelajah Penulis & Tag) akan mengisi pencarian yang sama.

↕ Urutkan & Filter

Ketuk tombol opsi tampilan (kanan atas) untuk memilih:

  • Tata Letak — Grid, Detail, Kompak, Minimalis, Tabel, atau Majalah
  • Urutkan — Judul, Penulis, Terakhir Dibaca, Tanggal Ditambahkan, Progres, Ukuran File, Seri
  • Tampilan — Letakkan buku Sedang Dibaca di awal dan buku Selesai di akhir
  • Filter — Berdasarkan format, tag, penulis, seri, atau rating

📚 Seri

Aktifkan Kelompokkan Berdasarkan Seri di bawah Tata Letak pada opsi tampilan, maka setiap seri dengan dua buku atau lebih di folder yang sedang Anda lihat akan diciutkan menjadi satu tumpukan yang menampilkan sampul, nama seri, dan berapa banyak bukunya yang telah Anda baca. Ketuk tumpukan untuk membuka layar seri: buku-buku dalam urutan baca, ditambah satu baris yang menyebutkan di folder mana saja buku itu berada jika seri tersebar di lebih dari satu folder. Tekan lama buku mana pun yang memiliki metadata seri dan pilih Lihat Seri untuk membuka layar yang sama. Pengelompokan berdasarkan seri tidak tersedia dalam tata letak Tabel dan Majalah.

Untuk melihat semua seri di perpustakaan Anda sekaligus, buka menu … dan pilih Semua Seri. Menu layar seri memungkinkan Anda Edit Urutan, Ganti Nama Seri…, dan mengubah Pengaturan Seri….

✔ Mode Seleksi

Tekan lama pada buku atau ketuk Pilih untuk masuk ke mode seleksi. Anda kemudian dapat memindahkan, menghapus, menyembunyikan, atau menampilkan kembali beberapa buku sekaligus.

📋 Bersihkan Duplikat

Buka Pengaturan > Perpustakaan > Pemeliharaan Perpustakaan > Bersihkan Duplikat untuk menemukan buku dengan judul, penulis, dan format yang sama. Untuk setiap kelompok duplikat:

  • Versi terbaru ditandai dengan lencana KEEP hijau
  • Pilih salinan lama menggunakan kotak centang (atau Pilih Semua)
  • Hapus — menghapus salinan lama yang dipilih
  • Salin Data & Hapus — memindahkan markah, sorotan, tag, kemajuan baca, dan penempatan rak ke versi terbaru sebelum menghapus
  • Aktifkan "Pindahkan buku baru ke rak & status tersembunyi buku lama" agar versi baru tetap di lokasi perpustakaan yang sama

Membaca Buku

Mode membaca EPUB, PDF, TXT, dan RTF.

📖 EPUB

EPUB dibuka di pembaca berfitur lengkap. Ketuk tepi kiri atau kanan untuk membalik halaman, atau geser.

  • Berpaginasi — membaca halaman per halaman secara tradisional dengan animasi geser, balik, atau tanpa animasi.
  • Gulir BerkelanjutanPremium — gulir secara alami melalui teks, tanpa pemisah halaman.
  • Arah Membaca — ikuti buku secara otomatis, atau atur sendiri kiri-ke-kanan atau kanan-ke-kiri. Lihat Arah Membaca.
  • Tata Letak Tetap — komik, buku bergambar, dan EPUB berhalaman tetap lainnya dibuka di pembaca yang dirancang khusus untuknya. Lihat Buku dengan Tata Letak Tetap.
  • Pencarian Dalam BukuPremium — cari kata atau frasa apa pun di seluruh buku. Lihat Pencarian Dalam Buku.
  • Galeri GambarPremium — jelajahi semua gambar di EPUB dari halaman detailnya. Lihat Galeri Gambar.
Tips: Sesuaikan ukuran font, spasi baris, dan warna tema di Pengaturan → Preferensi Membaca → Buku.

📄 PDF

PDF dirender secara native. Cubit untuk memperbesar, geser untuk membalik halaman. Aplikasi dapat mengingat kata sandi untuk PDF yang dilindungi.

📝 TXT & RTF

File teks biasa dan RTF dibuka di pembaca teks sederhana dengan format yang dapat disesuaikan.

Buku dengan Tata Letak Tetap

EPUB yang halamannya berupa desain tetap — komik, buku bergambar, dan judul dengan ilustrasi lebat.

📐 Apa Itu

Beberapa EPUB ditata halaman per halaman, bukan sebagai teks yang mengalir: setiap halaman adalah susunan tetap dari teks dan ilustrasi. Aplikasi mengenali buku semacam ini secara otomatis dan membukanya di pembaca yang dirancang khusus untuknya — setiap halaman diskalakan agar pas dengan layar Anda dan diposisikan di tengah, dengan ruang di sekitarnya diisi warna latar tema baca Anda.

👋 Membaca & Memperbesar

  • Ketuk sisi kiri atau kanan layar untuk membalik halaman, atau geser. Ketuk bagian tengah untuk menampilkan atau menyembunyikan toolbar.
  • Cubit untuk memperbesar — hingga tiga kali ukuran yang disesuaikan — lalu seret untuk berkeliling di halaman.
  • Ketuk dua kali untuk memperbesar bagian tersebut; ketuk dua kali lagi untuk menyesuaikan halaman kembali ke layar.
  • Buku yang diterbitkan untuk dibaca kanan-ke-kiri akan membalik halaman secara otomatis ke arah itu.

📖 Bentangan Dua Halaman

Putar perangkat ke mode lanskap dan halaman yang berhadapan akan muncul berdampingan. Aplikasi mengikuti petunjuk bentangan di dalam buku itu sendiri, sehingga sampul atau ilustrasi satu halaman penuh tetap mendapatkan halamannya sendiri. Putar kembali ke potret untuk satu halaman pada satu waktu.

ℹ Apa yang Tersedia

Daftar isi, penanda, slider kemajuan, riwayat membaca, dan melanjutkan dari tempat Anda berhenti semuanya berfungsi seperti biasa.

Karena setiap halaman adalah desain tetap, bukan teks yang dapat diatur ulang oleh aplikasi, beberapa kontrol tidak muncul untuk buku ini: Gulir Berkelanjutan dan gulir otomatis, pengaturan font dan tampilan, text-to-speech, pencarian dalam buku, serta pemilihan teks atau penyorotan.

Pencarian Dalam Buku

Temukan kata atau frasa apa pun di dalam buku yang sedang Anda baca.Premium

🔍 Memulai Pencarian

  1. Ketuk bagian tengah halaman untuk menampilkan toolbar.
  2. Ketuk kaca pembesar di ujung kanan bar bawah.
  3. Ketik setidaknya dua karakter dan tekan Cari di keyboard.

Seluruh buku akan dicari — setiap bab, bukan hanya bab yang ada di layar — dan pencocokan mengabaikan huruf besar/kecil. Pencarian tersedia di pembaca EPUB dan TXT/RTF.

📄 Menjelajahi Hasil

Hasil muncul di bawah bilah pencarian, dikelompokkan per bab. Setiap baris menampilkan bagian yang cocok dalam huruf tebal di dalam cuplikan teks di sekitarnya. Ketuk sebuah hasil untuk langsung melompat ke tempat itu — setiap kecocokan disorot kuning di buku, dengan kecocokan saat ini dalam warna ambar yang lebih pekat.

↕ Berpindah Antar Kecocokan

Setelah Anda memilih hasil, bilah pencarian menyusut menjadi strip ringkas dengan penghitung yang menunjukkan posisi Anda di antara kecocokan.

  • Gunakan panah atas/bawah untuk berpindah ke kecocokan sebelumnya atau berikutnya.
  • Ketuk tombol daftar untuk membuka kembali daftar hasil lengkap.
  • Ketuk × untuk mengakhiri pencarian — semua sorotan dihapus.

Galeri Gambar

Jelajahi semua ilustrasi di EPUB sebagai galeri yang dapat digeser.Premium

🖼 Membuka Galeri

Buka halaman detail buku EPUB dan ketuk tombol tumpukan foto 🖼 di toolbar kanan atas. Aplikasi mengekstrak setiap gambar dari buku, menampilkan bilah kemajuan selama bekerja — ketuk tombol × di kiri atas untuk keluar kapan saja. Galeri hanya tersedia untuk buku EPUB.

📚 Apa yang Akan Anda Lihat

Gambar muncul satu per halaman dalam urutan baca — urutan kemunculannya di bab-bab buku — termasuk sampul. Gambar mungil seperti ikon dan hiasan dilewati: apa pun yang lebih kecil dari ukuran minimum (100 px secara default) tidak disertakan. Sesuaikan ambangnya di Pengaturan → Preferensi Membaca → Buku → Galeri EPUB. Jika tidak ada gambar yang memenuhi syarat, galeri akan memberi tahu bahwa tidak ada gambar yang ditemukan.

👆 Melihat & Menyimpan Gambar

  • Geser untuk berpindah antar gambar, atau gunakan slider halaman di bagian bawah untuk melompat dengan cepat.
  • Cubit atau ketuk dua kali untuk memperbesar, lalu seret untuk berkeliling — galeri menggunakan pembaca komik, sehingga cara memperbesarnya sama persis. Lihat Memperbesar Halaman Komik.
  • Ketuk bagian tengah layar untuk menampilkan atau menyembunyikan kontrol.
  • Tekan lama sebuah gambar untuk Lihat Resolusi Penuh — yang membukanya dalam ukuran aslinya untuk melihat lebih dekat — atau untuk Simpan ke Foto, Simpan ke File, atau Salin Gambar.
  • Galeri mengikuti arah baca komik Anda — termasuk gulir vertikal gaya webtoon.

Font Bacaan

Pilih font bacaan, tambahkan milik Anda sendiri, atau unduh paket bahasa.

🔤 Memilih Font

Buka Pengaturan → Preferensi Membaca → Buku → Font Kustom untuk membuka layar Font. Beberapa font bacaan sudah tersedia bawaan, dengan Literata sebagai default. Font yang Anda pilih berlaku untuk pembaca EPUB dan teks.

Tips: Sesuaikan ukuran font dan spasi baris di Pengaturan → Preferensi Membaca → Buku.

👓 Font Aksesibilitas

Dua font yang dirancang agar lebih mudah dibaca disertakan dan selalu tersedia: Atkinson Hyperlegible, yang mempertajam perbedaan antara huruf-huruf yang mirip, dan OpenDyslexic, yang dibobot untuk mengurangi tertukarnya huruf.

📂 Font Kustom

Impor file font .ttf atau .otf milik Anda sendiri dari layar Font dan gunakan di pembaca EPUB. Font yang diimpor tetap tersimpan di perangkat Anda.

📥 Unduh Font & Paket Bahasa

Di bawah Unduh Font, font bacaan tambahan dan paket bahasa tersedia sesuai permintaan untuk aksara yang tidak disertakan aplikasi — Tionghoa, Jepang & Korea (CJK), Arab, Devanagari, dan Thai. Paketnya besar (sekitar 41 MB masing-masing), jadi ukurannya ditampilkan sebelum Anda mengunduh. Setelah terpasang, paket bekerja persis seperti font yang diimpor.

Tips: Jika karakter dalam sebuah buku tampil sebagai kotak kosong, unduh paket bahasa yang sesuai untuk menampilkannya.

📜 Lisensi Font

Font bawaan dan yang dapat diunduh disediakan di bawah SIL Open Font License. Anda dapat membaca lisensi lengkap untuk masing-masing dari barisnya di layar Font.

Arah Membaca

Kiri ke kanan, kanan ke kiri, atau sesuai arah penerbitan buku.

⇄ Memilih Arah

Buka Pengaturan → Preferensi Membaca → Buku dan gunakan kontrol Arah Membaca di bawah Mode Baca:

  • Otomatis (default) — mengikuti arah yang dinyatakan oleh buku itu sendiri. Manga dan buku yang diterbitkan untuk dibaca kanan-ke-kiri terbuka dengan arah yang benar tanpa perlu diatur.
  • Kiri ke Kanan — standar untuk sebagian besar buku Barat.
  • Kanan ke Kiri — gunakan kanan-ke-kiri untuk setiap buku.

Anda juga dapat mengubahnya tanpa keluar dari buku: ketuk bagian tengah halaman untuk menampilkan toolbar, lalu ketuk tombol Aa di bar bawah. Perubahan langsung berlaku pada halaman yang sedang Anda baca.

👋 Apa yang Mengikuti Arah Ini

  • Sisi mana yang membawa Anda maju — dalam buku kanan-ke-kiri, mengetuk atau menggeser ke kiri membalik ke halaman berikutnya.
  • Animasi balik halaman, yang membalik dari sisi yang benar.
  • Tata letak teks pada halaman.
Catatan: Slider kemajuan selalu terisi dari kiri, karena ia menunjukkan seberapa jauh Anda dalam buku, bukan posisi halaman di layar.

ℹ Di Mana Ini Berlaku

Pengaturan ini berlaku untuk EPUB dalam mode berpaginasi — tersembunyi saat Gulir Berkelanjutan aktif. Komik memiliki pengaturan urutan baca sendiri (lihat Membaca Komik), dan buku dengan tata letak tetap selalu mengikuti arah yang dinyatakan dalam buku.

Penulisan Vertikal

Buku Jepang dan Tionghoa yang ditata dalam kolom vertikal.

⬇ Buku Vertikal

Buku yang ditata secara vertikal — tategaki Jepang (縦書き) dan Tionghoa tradisional (直排) — ditampilkan sesuai penataan aslinya: teks berjalan dari atas ke bawah dalam kolom yang terisi dari kanan ke kiri, dan halaman berbalik ke kiri, sama seperti cara membaca manga.

⚙ Arah Menulis

Buka Pengaturan → Preferensi Membaca → Buku dan gunakan kontrol Arah Menulis:

  • Otomatis (default) — mengikuti tata letak masing-masing buku. Buku yang ditata secara vertikal akan ditampilkan secara vertikal; buku lainnya tidak terpengaruh.
  • Horizontal — tata semua buku secara horizontal, termasuk yang ditata secara vertikal.
  • Vertikal — tata semua buku dalam kolom vertikal.

Kontrol yang sama juga ada di pengaturan dalam pembaca, di bawah tombol Aa.

Catatan: Perubahan berlaku saat Anda berikutnya membuka sebuah buku — buku yang sedang terbuka mempertahankan tata letak saat dibuka.

ℹ Baik untuk Diketahui

  • Buku vertikal selalu menggunakan mode berpaginasi, sehingga Gulir Berkelanjutan dan gulir otomatis tidak tersedia untuknya.
  • Animasi halaman Geser tidak digunakan untuk buku vertikal — buku ini berbalik dengan animasi Balik.
  • Penanda, sorotan, daftar isi, pencarian dalam buku, dan text-to-speech semuanya berfungsi seperti biasa.

Membaca Komik

Membaca komik CBZ, CBR, dan CB7.

📱 Mode Membaca

  • Kiri-ke-Kanan — Urutan halaman komik Barat standar.
  • Kanan-ke-Kiri — Urutan baca manga.
  • Webtoon / Gulir Vertikal — Gulir vertikal halus untuk komik strip panjang.

Atur default global di Pengaturan → Preferensi Membaca → Komik, atau ubah per buku dari halaman detailnya.

🔎 Skala Halaman

  • Sesuai Layar — Seluruh halaman terlihat.
  • Sesuai Lebar — Mengisi lebar, gulir vertikal jika perlu.
  • Sesuai Tinggi — Mengisi tinggi.
  • Ukuran Asli — Tampilan piksel 1:1.

👋 Gestur

  • Geser kiri/kanan untuk membalik halaman (mode paginasi).
  • Cubit atau ketuk dua kali untuk memperbesar, lalu seret untuk berkeliling. Lihat Memperbesar Halaman Komik.
  • Ketuk tengah halaman untuk menampilkan atau menyembunyikan toolbar.
  • Gunakan slider halaman di bawah untuk melompat dengan cepat.

⚠ Peringatan Arsip Mencurigakan

Ketika Anda membuka arsip komik (CBZ, CBR, atau CB7) yang isinya terlihat luar biasa besar atau dikompresi secara agresif — pola yang digunakan oleh file “zip bomb” yang dirancang untuk membebani memori — aplikasi akan menampilkan peringatan Arsip Mencurigakan sebelum mengekstrak apa pun.

  • Ketuk Batal untuk tidak membuka file. Ini adalah pilihan aman untuk arsip dari sumber tak dikenal.
  • Ketuk Tetap Buka jika Anda memercayai file tersebut — aplikasi akan melewati pemeriksaan keamanan dan memuat halaman.

File EPUB menggunakan perlindungan yang sama secara diam-diam saat impor.

Memperbesar Halaman Komik

Lihat lebih dekat karya seninya — baik dalam mode halaman maupun gulir webtoon.

🔍 Mode Halaman

  • Cubit untuk memperbesar, hingga tiga kali ukuran yang disesuaikan. Karya seni tetap mengikuti jari Anda saat mencubit.
  • Ketuk dua kali untuk langsung memperbesar dua kali lipat pada titik tersebut; ketuk dua kali lagi untuk menyesuaikan halaman kembali ke layar.
  • Seret dengan satu jari untuk berkeliling saat diperbesar.
  • Mencubit hampir sepenuhnya kembali membuat halaman langsung pas dengan rapi.

Memperbesar berfungsi dengan opsi skala Sesuai Layar dan Sesuai Tinggi, serta dengan bentangan dua halaman. Sesuai Lebar dan Ukuran Asli sudah menampilkan halaman lebih besar dari layar dan menggulir sebagai gantinya — gunakan Lihat Resolusi Penuh di bawah untuk melihat lebih dekat di sana.

📱 Gulir Webtoon

  • Cubit atau ketuk dua kali untuk memperbesar seluruh strip, hingga tiga kali ukuran normalnya.
  • Gulir tetap berfungsi saat Anda memperbesar — cukup seret ke atas dan bawah seperti biasa.
  • Seret ke samping untuk berkeliling di halaman yang diperbesar.
  • Level perbesaran tetap bertahan saat Anda terus menggulir, sehingga Anda dapat membaca satu bab penuh dalam ukuran besar. Memutar perangkat mengembalikannya ke ukuran normal.

✨ Lihat Resolusi Penuh

Memperbesar akan membesarkan halaman pada ukuran yang disiapkan untuk layar Anda. Untuk tampilan paling tajam pada satu halaman, tekan lama halaman tersebut dan pilih Lihat Resolusi Penuh — halaman itu akan didekode pada resolusi asli arsipnya, dan Anda dapat mencubit jauh lebih dekat lagi. Ketuk dua kali untuk beralih antara menyesuaikan layar dan ukuran dua kali lipat; geser ke bawah atau ketuk tombol tutup untuk kembali.

Catatan: Perbesaran tidak disimpan. Menutup buku akan selalu kembali ke penyesuaian normal.

Text-to-Speech & CarPlay

Dengarkan buku Anda dibacakan dengan suara.

🔊 Menggunakan Text-to-Speech

Buka buku EPUB, PDF, atau TXT mana pun dan ketuk tombol putar di toolbar. TTS membaca satu kalimat pada satu waktu dan menyorot kata yang sedang dibaca.

  • Kecepatan — 0,5× hingga 2× di kontrol TTS.
  • Suara — Pilih dari 100+ suara sistem di Pengaturan → Preferensi Membaca → Text-to-Speech.
  • Lewati — Ketuk berikutnya/sebelumnya untuk melompat per kalimat, atau per bab.
Catatan: Buku dengan tata letak tetap — komik dan buku bergambar yang halamannya berupa desain tetap — tidak memiliki teks untuk dibacakan aplikasi, sehingga tombol putar tidak ditampilkan untuk buku tersebut.

🚗 CarPlay

Saat terhubung ke kendaraan yang kompatibel dengan CarPlay, aplikasi muncul di layar mobil Anda dengan kontrol pemutaran yang disederhanakan. TTS terus diputar di latar belakang — tidak perlu menjaga layar tetap menyala.

Tips: Aktifkan Audio Latar BelakangPremium di pengaturan TTS untuk menjaga pemutaran tetap berjalan saat aplikasi di latar belakang, bahkan tanpa CarPlay.

AI Comic Upscaling

Tingkatkan halaman komik resolusi rendah di perangkat.Premium

✨ Apa Fungsinya

Menggunakan model machine learning di perangkat untuk meningkatkan skala halaman komik yang berada di bawah ambang resolusi. Hasilnya adalah garis yang lebih tajam dan artefak kompresi yang kurang terlihat — sangat membantu untuk pindaian lama atau berkualitas rendah.

⚙ Pengaturan

  1. Buka Pengaturan → Preferensi Membaca → Komik → AI Upscaling.
  2. Nyalakan.
  3. Sesuaikan Ambang Resolusi — halaman di bawah lebar piksel ini akan ditingkatkan (default: 1500 px).
  4. Atur Jendela Prefetch untuk mengontrol berapa banyak halaman mendatang yang diproses terlebih dahulu di latar belakang.
  5. Pilih Level Denoise (Auto biasanya yang terbaik).

💾 Cache & Penyimpanan

Gambar yang ditingkatkan disimpan dalam cache sehingga tidak perlu diproses ulang. Pilih berapa lama cache disimpan (7–90 hari atau tidak pernah kedaluwarsa), dan hapus kapan saja dari pengaturan.

Tips: Lencana indikator kecil muncul pada halaman yang ditingkatkan. Anda dapat menonaktifkannya di pengaturan jika mau.

Buku Tersembunyi

Jaga privasi buku tertentu.Premium

👁 Menyembunyikan Buku

  1. Buka halaman detail buku dan ketuk menu (…).
  2. Pilih Sembunyikan Buku.
  3. Buku menghilang dari tampilan perpustakaan normal.

Untuk menyembunyikan banyak buku sekaligus, gunakan Mode Seleksi.

🔓 Melihat Buku Tersembunyi

Tarik ke bawah pada perpustakaan untuk mengaktifkan Mode Tersembunyi. Semua buku Anda — tersembunyi dan terlihat — sekarang ditampilkan. Tarik lagi atau tinggalkan aplikasi untuk keluar dari mode tersembunyi.

🔒 Opsi Privasi

Saat mode tersembunyi aktif, buka Pengaturan → Mode Tersembunyi untuk memilih apa yang terjadi saat Anda meninggalkan aplikasi:

  • Keluar otomatis (default) — Mode tersembunyi mati secara otomatis. Cepat dan sederhana.
  • Memerlukan Face ID / Touch ID — Mode tersembunyi tetap aktif, tetapi memerlukan autentikasi biometrik saat Anda kembali. Lebih aman.

↩ Menampilkan Kembali Buku

Saat dalam mode tersembunyi, buka detail buku tersembunyi dan pilih Tampilkan Buku, atau gunakan Mode Seleksi untuk menampilkan kembali secara massal.

☁ Menyinkronkan Buku Tersembunyi

Dalam mode tersembunyi, buka Pengaturan → Mode Tersembunyi dan aktifkan Sinkronkan Buku Tersembunyi dengan iCloud:

  • Nonaktif (default) — buku tersembunyi hanya tetap ada di perangkat ini. Menyembunyikan buku juga menghapusnya dari iCloud.
  • Aktif — buku tersembunyi disinkronkan melalui iCloud tetapi tetap tersembunyi di setiap perangkat tempat Anda masuk.

Menonaktifkan sakelar saat Anda sudah memiliki buku tersembunyi di iCloud akan menanyakan apa yang harus dilakukan dengan buku tersebut:

  • Simpan di Semua Perangkat — perangkat lain Anda tetap menyimpan salinan yang tersinkronkan; perangkat ini menyimpan salinan pribadi khusus lokal.
  • Hapus Sepenuhnya dari iCloud — menghapus buku dari iCloud; setiap perangkat lain menyimpan salinan pribadinya sendiri di perpustakaan tersembunyinya.
Catatan: Jika salah satu perangkat lain Anda menghapus buku tersembunyi dari iCloud, perangkat ini secara otomatis menyimpan salinan pribadinya sendiri di perpustakaan tersembunyi — selama file buku tersebut sudah diunduh di sana.

🗑 Hapus Buku Tersembunyi Secara Permanen

Dalam mode tersembunyi, buka Pengaturan → Mode Tersembunyi dan pilih Hapus Buku Tersembunyi Secara Permanen untuk menghapus setiap buku tersembunyi dari perangkat ini, dari iCloud, dan dari perangkat lain Anda. Ketik DELETE untuk mengonfirmasi.

Peringatan: Tindakan ini tidak dapat dibatalkan. Perangkat yang sedang offline pada saat itu akan menyimpan salinan lokalnya hingga sinkronisasi berikutnya.

Riwayat Membaca

Lompat kembali ke posisi mana pun yang baru-baru ini Anda kunjungi.

🕒 Penyimpanan Otomatis

Setiap kali Anda menutup buku atau mengirim aplikasi ke latar belakang, posisi Anda saat ini disimpan sebagai entri riwayat — tidak perlu mengingat untuk menandai. Ini berfungsi di setiap pembaca: EPUB, PDF, TXT/RTF, dan komik.

  • Hingga 50 posisi terbaru disimpan per buku. Entri yang lebih lama dihapus secara otomatis ketika yang baru masuk.
  • Menutup buku lagi di tempat yang sama dalam beberapa menit akan memperbarui entri yang ada, bukan membuat duplikat.
  • Posisi yang disimpan otomatis dipisahkan dari daftar penanda manual Anda agar tidak bercampur dengan yang Anda buat secara sengaja.

📖 Riwayat di Dalam Buku

Saat membaca, ketuk menu lainnya (…) di kanan atas dan pilih Riwayat Membaca. Anda akan melihat daftar posisi terbaru Anda dalam buku itu, terbaru dulu, dengan nama bab atau halaman dan berapa lama yang lalu setiap entri direkam.

  • Ketuk entri apa pun untuk langsung melompat ke tempat itu.
  • Geser entri ke kiri untuk menghapusnya.

📚 Riwayat di Seluruh Perpustakaan

Dari perpustakaan, ketuk menu lainnya (…) di toolbar atas dan pilih Riwayat Membaca untuk melihat setiap buku yang baru-baru ini Anda buka, dikelompokkan berdasarkan hari. Ketuk baris untuk membuka buku tepat di tempat Anda berhenti.

Sinkronisasi iCloud

Jaga perpustakaan Anda tetap sinkron di semua perangkat.

☁ Mengaktifkan Sinkronisasi

  1. Buka Pengaturan → Sinkronisasi iCloud.
  2. Nyalakan Sinkronkan Perpustakaan dengan iCloud.
  3. Sinkronisasi berlaku pada peluncuran aplikasi berikutnya.

Metadata, progres membaca, penanda, sorotan, dan rak Anda disinkronkan di semua perangkat yang masuk ke akun iCloud yang sama.

📊 Status Sinkronisasi

Pengaturan → Sinkronisasi iCloud menampilkan kartu status untuk file buku Anda:

  • Judul utama — Terkini, Menyinkronkan… (dengan jumlah), atau Belum masuk.
  • Bilah yang menunjukkan seberapa banyak file perpustakaan Anda yang ada di iCloud.
  • Rincian — Tersinkron (dengan ukuran total), Hanya di iCloud (belum diunduh ke perangkat ini), dan Sedang berlangsung.
Catatan: Kartu ini hanya melacak file buku. Progres membaca, penanda, sorotan, dan rak disinkronkan secara terpisah dan otomatis, apa pun status filenya.

☁ Lencana Sampul

Sampul buku menampilkan ikon awan kecil di sudut kanan bawah untuk menunjukkan status sinkronisasi file:

  • Ikon awan — file hanya ada di iCloud. Buka halaman buku untuk mengunduhnya.
  • Panah atas/bawah — file sedang diunggah atau diunduh.
  • Tanpa ikon — file sudah ada di perangkat ini.

📥 Unduh Otomatis

Pilih ukuran file maksimum untuk unduhan otomatis. Buku yang lebih besar tetap di cloud sampai Anda membukanya. Sesuaikan batasnya di pengaturan iCloud.

WebDAV & OPDS

Telusuri dan unduh dari server dan katalog jarak jauh.

🗄 WebDAV

Hubungkan ke NAS, Nextcloud, atau server Calibre untuk menelusuri folder dan mengunduh buku.

  1. Buka Pengaturan → Impor Buku → WebDAV.
  2. Ketuk Tambah Server dan masukkan URL.
  3. Tambahkan nama pengguna dan kata sandi jika diperlukan.
  4. Ketuk Uji Koneksi, lalu simpan.
Sertifikat self-signed: Jika server Anda menggunakan sertifikat self-signed, Anda dapat menyalakan Izinkan Sertifikat Tidak Tepercaya. Aplikasi akan meminta Anda mengonfirmasi terlebih dahulu — ini menonaktifkan validasi TLS, sehingga siapa pun di jaringan Anda dapat menyamar sebagai server. Aktifkan hanya untuk server yang Anda kendalikan.

📚 Katalog OPDS

OPDS adalah standar terbuka untuk katalog buku. Tambahkan katalog publik (Project Gutenberg, Standard Ebooks, dll.) atau server pribadi Anda sendiri.

  1. Buka Pengaturan → Impor Buku → OPDS.
  2. Ketuk Tambah Katalog dan masukkan URL feed.
  3. Telusuri kategori dan unduh buku ke perpustakaan Anda.
