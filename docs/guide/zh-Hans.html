导入图书

多种方式将图书添加到您的书库。

📁 从"文件"App

点击 设置 → 导入图书，然后从设备、iCloud Drive 或任何已连接的云服务中选择文件。在 iPad 上还可以使用拖放操作。

🌐 WiFi 传输

从 WiFi 网络上的任何电脑或手机上传图书。详情请参阅下方的专属章节。

🗂 WebDAV & OPDS

连接到 NAS、Calibre 服务器或公共图书目录，直接浏览和下载图书。请参阅下方。

WiFi 传输

从本地网络上的任何设备上传图书。

📶 工作原理

应用在您的设备上运行一个小型网页服务器。同一 WiFi 网络上的任何电脑或手机都可以在浏览器中打开上传页面。

  1. 前往 设置 → 导入图书 → WiFi 传输。
  2. 点击 启动服务器，将显示类似 http://192.168.1.42:8080 的地址。
  3. 在同一网络的任何浏览器中打开该地址。
  4. 将文件拖到页面上或点击浏览 — 按需选择目标文件夹。
  5. 导入的图书会立即出现在您的书库中。
  6. 完成后点击 停止服务器。
提示：服务器运行期间设备将保持唤醒状态，以免传输中断。
上传失败？每个失败的文件会在所在行直接显示原因。如果 WiFi 连接中断，请点击该行中的 ↻ 重试 再次发送。对于无法解决的问题（例如不支持的文件格式），不会显示重试按钮。

书库 & 整理

查找、排序和整理您的图书。

🔍 搜索

点击书库底部的搜索胶囊按钮以展开搜索框，然后点击完成关闭它。可按书名、作者、标签、系列、出版社和描述进行搜索。从图书的上下文菜单按作者或标签搜索（参见按作者和标签浏览）会填入相同的搜索内容。

↕ 排序 & 筛选

点击视图选项按钮（右上角）进行选择：

  • 布局 — 网格、详细、紧凑、极简、表格或杂志
  • 排序 — 书名、作者、最近阅读、添加日期、进度、文件大小、系列
  • 显示 — 将正在阅读的书排在前面，已完成的排在最后
  • 筛选 — 按格式、标签或作者

✔ 选择模式

长按一本书或点击 选择 进入选择模式。然后可以一次移动、删除、隐藏或取消隐藏多本书。

📋 清理重复项

前往 设置 > 书库 > 书库维护 > 清理重复项，查找标题、作者和格式相同的图书。对于每个重复组：

  • 最新版本会标有绿色的 KEEP 徽章
  • 使用复选框选择较旧的副本（或 全选）
  • 删除 — 移除所选的较旧副本
  • 复制数据并删除 — 在删除之前将书签、高亮、标签、阅读进度和书架归属转移到最新版本
  • 启用 “将新书移动到旧书的书架和隐藏状态”，以将新版本保留在书库中的同一位置

阅读图书

EPUB、PDF、TXT 和 RTF 阅读模式。

📖 EPUB

EPUB 文件在基于 Readium 的全功能阅读器中打开。点击左右边缘翻页，或者滑动。

  • 分页模式 — 传统的逐页阅读。
  • 连续滚动Premium — 自然滚动阅读文本，无分页。
  • 阅读方向 — 让图书自动跟随方向，或自行设置从左到右或从右到左。详见阅读方向。
  • 固定版式 — 漫画、绘本等以逐页方式排版的 EPUB 会用专为其打造的阅读器打开。详见固定版式图书。
  • 书内搜索Premium — 在整本书中搜索任意字词或短语。详见书内搜索。
  • 图片库Premium — 在图书详情页浏览 EPUB 中的所有图片。详见图片库。
提示：在 设置 → 阅读偏好 → 图书 中调整字体大小、行间距和主题颜色。

📄 PDF

PDF 文件原生渲染。双指缩放，滑动翻页。应用可以记住受保护 PDF 的密码。

📝 TXT & RTF

纯文本和 RTF 文件在简单的文本阅读器中打开，可调整格式。

固定版式图书

页面为固定设计的 EPUB — 例如漫画、绘本和大量插图的图书。

📐 版式说明

部分 EPUB 采用逐页排版，而非可重排的正文：每一页都是文字与插图的固定排列。应用会自动识别此类图书，并用专为其打造的阅读器打开 — 每一页都会缩放以适应屏幕并居中显示，周围空白处会填充为您阅读主题的背景色。

👋 阅读与缩放

  • 点击屏幕左侧或右侧翻页，或者滑动。点击中间可显示或隐藏工具栏。
  • 双指捏合放大 — 最多可放大至适应大小的三倍 — 然后拖动以在页面上移动。
  • 双击可放大该处；再次双击可让页面恢复适应屏幕大小。
  • 发布为从右到左阅读的图书会自动按此方向翻页。

📖 双页跨页

将设备转为横屏，相对的两页会并排显示。应用会遵循图书内部的跨页提示，因此封面或整页插图仍会单独占一页。转回竖屏后则恢复为一次显示一页。

ℹ 支持的功能

目录、书签、进度滑块、阅读历史，以及从上次位置继续阅读等功能均正常可用。

由于每一页都是固定设计，而非应用可以重排的文本，此类图书不提供以下几项功能：连续滚动和自动滚动、字体与外观设置、文字转语音、书内搜索，以及文本选择或高亮。

书内搜索

在正在阅读的书中查找任意字词或短语。Premium

🔍 开始搜索

  1. 点击页面中央以显示工具栏。
  2. 点击底部工具栏右端的放大镜。
  3. 输入至少两个字符，然后按键盘上的 搜索。

搜索范围是整本书 — 所有章节，而不仅仅是屏幕上显示的章节 — 且匹配不区分大小写。搜索功能在 EPUB 和 TXT/RTF 阅读器中可用。

📄 浏览结果

结果显示在搜索栏下方，按章节分组。每一行都会在一段上下文摘录中以粗体显示匹配内容。点击某个结果即可直接跳转到该处 — 书中的所有匹配项都会以黄色高亮显示，当前匹配项则以更深的琥珀色显示。

↕ 在匹配项之间跳转

选择某个结果后，搜索栏会折叠为一个紧凑的条带，并带有计数器，显示您当前位于第几个匹配项。

  • 使用上下箭头跳到上一个或下一个匹配项。
  • 点击列表按钮可重新打开完整的结果列表。
  • 点击 × 结束搜索 — 所有高亮都会被移除。

图片库

以可滑动的图库形式浏览 EPUB 中的每一幅插图。Premium

🖼 打开图片库

打开某本 EPUB 图书的详情页，点击右上角工具栏中的照片堆叠按钮 🖼。应用会从书中提取所有图片，处理期间会显示进度条 — 点击左上角的 × 按钮可随时退出。图片库仅适用于 EPUB 图书。

📚 您会看到的内容

图片按阅读顺序 — 即它们在书中各章节出现的顺序 — 每页显示一张，并包含封面。图标和装饰等细小图片会被跳过：小于最小尺寸（默认为 100 px）的图片不会显示。可在 设置 → 阅读偏好 → 图书 → EPUB 图库 中调整该阈值。如果没有符合条件的图片，图库会提示未找到任何图片。

👆 查看与保存图片

  • 滑动即可在图片之间切换，或使用底部的页面滑块快速跳转。
  • 双指捏合或双击缩放，然后拖动以四处查看 — 图片库使用漫画阅读器，因此缩放方式完全相同。详见缩放漫画页面。
  • 点击屏幕中央可显示或隐藏控制项。
  • 长按图片可查看完整分辨率 — 以原始大小打开图片以查看更多细节 — 或保存到"照片"、保存到"文件"、复制图片。
  • 图片库会遵循您的漫画阅读方向 — 包括 Webtoon 式垂直滚动。

阅读字体

选择阅读字体、添加自己的字体，或下载语言包。

🔤 选择字体

打开 设置 → 阅读偏好 → 图书 → 自定义字体 进入字体界面。应用内置了多款阅读字体，默认字体为 Literata。所选字体将应用于 EPUB 和文本阅读器。

提示：在 设置 → 阅读偏好 → 图书 中调整字体大小和行间距。

👓 无障碍字体

内置了两款专为便于阅读而设计、随时可用的字体：Atkinson Hyperlegible 强化了相似字母之间的差异，OpenDyslexic 则加重了字母底部，以减少字母混淆。

📂 自定义字体

在字体界面导入您自己的 .ttf 或 .otf 字体文件，即可在 EPUB 阅读器中使用。导入的字体仅保留在您的设备上。

📥 下载字体和语言包

在下载字体中，可按需获取应用未随附的文字系统所需的额外阅读字体和语言包 — 中文、日文和韩文（CJK）、阿拉伯文、天城文和泰文。语言包体积较大（每个约 41 MB），因此下载前会显示大小。安装后，它们的使用方式与导入的字体完全相同。

提示：如果书中的字符显示为空白方框，请下载相应的语言包以显示它们。

📜 字体许可

内置和可下载的字体均依据 SIL Open Font License 提供。您可以在字体界面的每一行中阅读相应字体的完整许可协议。

阅读方向

从左到右、从右到左，或按图书发布时的方向。

⇄ 选择方向

打开 设置 → 阅读偏好 → 图书，在阅读模式下使用阅读方向控件：

  • 自动（默认）— 跟随图书自身声明的方向。漫画及发布为从右到左阅读的图书，无需任何设置即可正确打开。
  • 从左到右 — 大多数西方图书的标准方式。
  • 从右到左 — 对所有图书都使用从右到左。

您也可以不离开图书直接更改：点击页面中央显示工具栏，然后点击底部工具栏中的 Aa 按钮。更改会立即应用到您正在阅读的页面。

👋 跟随方向变化的内容

  • 哪一侧带您前进 — 在从右到左的图书中，向左点击或滑动会翻到下一页。
  • 翻页动画，会从正确的一侧翻起。
  • 页面上文字的排版方式。
注意：进度滑块始终从左侧开始填充，因为它显示的是您在全书中的阅读进度，而非页面在屏幕上的位置。

ℹ 适用范围

此设置适用于分页模式下的 EPUB — 开启连续滚动时会隐藏。漫画有自己的阅读顺序设置（参见阅读漫画），固定版式图书则始终遵循图书内声明的方向。

竖排书写

以竖排版式排版的日文与中文图书。

⬇ 竖排图书

竖排图书 — 包括日文的縦書き和中文的直排 — 会按照原始排版方式显示：文字从上到下排成列，各列从右向左依次排开，翻页方向也是向左，与漫画的阅读方向相同。

⚙ 书写方向

打开 设置 → 阅读偏好 → 图书，使用书写方向控件：

  • 自动（默认）— 跟随每本书自身的排版。以竖排方式排版的图书会以竖排显示；其他图书则不受影响。
  • 横排 — 将所有图书都以横排显示，包括本身以竖排排版的图书。
  • 竖排 — 将所有图书都以竖排列显示。

阅读器内设置中同样有此控件，位于 Aa 按钮下。

注意：更改将在您下次打开图书时生效 — 当前正在阅读的图书会保持打开时的排版方式。

ℹ 须知事项

  • 竖排图书始终使用分页模式，因此连续滚动和自动滚动对它们不可用。
  • 竖排图书不使用滑动翻页动画 — 而是使用翻转动画。
  • 书签、高亮、目录、书内搜索和文字转语音均可正常使用。

阅读漫画

CBZ、CBR 和 CB7 漫画阅读。

📱 阅读模式

  • 从左到右 — 标准西方漫画页序。
  • 从右到左 — 日式漫画阅读顺序。
  • Webtoon / 垂直滚动 — 适合长条漫画的流畅垂直滚动。

在 设置 → 阅读偏好 → 漫画 中设置全局默认值，或在图书详情页为单本书更改。

🔎 页面缩放

  • 适合屏幕 — 显示完整页面。
  • 适合宽度 — 填满宽度，需要时垂直滚动。
  • 适合高度 — 填满高度。
  • 原始大小 — 1:1 像素显示。

👋 手势

  • 左右滑动翻页（分页模式）。
  • 双指捏合或双击缩放，然后拖动以四处查看。详见缩放漫画页面。
  • 点击页面中央显示或隐藏工具栏。
  • 使用底部的页面滑块快速跳转。

⚠ 可疑压缩包提示

当您打开一个漫画压缩包（CBZ、CBR 或 CB7），其内容看起来异常巨大或被过度压缩 — 这正是“压缩炸弹”文件用来撑爆内存的典型特征 — 应用会在解压任何内容之前显示可疑压缩包提示。

  • 点击 取消，不打开该文件。对于来源不明的压缩包，这是安全的选择。
  • 如果您信任该文件，可点击 仍然打开 — 应用将跳过安全检查并加载页面。

EPUB 文件在导入时会以相同方式静默使用该保护。

缩放漫画页面

更贴近画面细节 — 无论是分页模式还是 Webtoon 滚动模式。

🔍 分页模式

  • 双指捏合放大，最多可放大至适应大小的三倍。画面会随您手指的移动而缩放。
  • 双击可直接放大到该处的两倍大小；再次双击可让页面恢复适应屏幕大小。
  • 放大后可用单指拖动查看不同区域。
  • 将双指几乎捏合到底时，页面会自动整齐地恢复适应大小。

缩放功能适用于适合屏幕和适合高度缩放选项，也适用于双页跨页。适合宽度和原始大小本身就会将页面显示得比屏幕更大并改为滚动 — 如需在这两种模式下查看细节，请使用下方的查看完整分辨率。

📱 Webtoon 滚动

  • 双指捏合或双击可放大整条漫画，最多可放大至正常大小的三倍。
  • 放大后仍可继续滚动 — 像平常一样上下拖动即可。
  • 横向拖动可在放大的页面上左右移动。
  • 继续滚动时缩放级别保持不变，因此可以放大阅读整个章节。旋转设备会恢复正常大小。

✨ 查看完整分辨率

平常的缩放放大的是已经为屏幕准备好的页面尺寸。如果想以最清晰的效果查看某一页，请长按该页并选择 查看完整分辨率 — 该页会按压缩包中的原始分辨率解码，您可以进一步捏合放大更多。双击可在适应屏幕大小与两倍大小之间切换；向下滑动或点击关闭按钮可返回。

注意：缩放不会被保存。关闭图书后始终会恢复正常适应大小。

文字转语音 & CarPlay

聆听图书朗读。

🔊 使用文字转语音

打开任意 EPUB、PDF 或 TXT 图书，点击工具栏中的播放按钮。文字转语音逐句朗读并高亮当前单词。

  • 速度 — 在 TTS 控件中选择 0.5× 到 2×。
  • 语音 — 在 设置 → 阅读偏好 → 文字转语音 中从 100 多种系统语音中选择。
  • 跳过 — 点击下一句/上一句按钮按句或按章跳转。
注意：固定版式图书 — 页面为固定设计的漫画和绘本 — 没有可供应用朗读的文字，因此不会显示播放按钮。

🚗 CarPlay

连接到支持 CarPlay 的车辆后，应用会在车载显示屏上显示简化的播放控件。文字转语音在后台继续播放 — 无需保持屏幕常亮。

提示：在 TTS 设置中启用 后台音频Premium，即使不使用 CarPlay 也能在应用进入后台时继续播放。

AI 漫画增强

在设备上增强低分辨率漫画页面。Premium

✨ 功能介绍

使用设备上的机器学习模型来放大低于分辨率阈值的漫画页面。效果是线条更清晰，压缩伪影更少 — 对于旧的或低质量的扫描件特别有帮助。

⚙ 设置

  1. 前往 设置 → 阅读偏好 → 漫画 → AI 增强。
  2. 打开开关。
  3. 调整 分辨率阈值 — 宽度低于此像素值的页面将被增强（默认：1500 px）。
  4. 设置 预取窗口 来控制在后台预处理多少即将到来的页面。
  5. 选择 降噪级别（自动通常最佳）。

💾 缓存 & 存储

增强后的图像会被缓存，无需重新处理。选择缓存保留时间（7–90 天或永不过期），并可随时在设置中清除。

提示：增强后的页面上会显示一个小标记。如果您不需要，可以在设置中关闭。

隐藏图书

将某些图书保持私密。Premium

👁 隐藏图书

  1. 打开图书详情页并点击菜单（…）。
  2. 选择 隐藏图书。
  3. 图书将从正常的书库视图中消失。

要一次隐藏多本书，请使用选择模式。

🔓 查看隐藏图书

在书库中下拉即可激活 隐藏模式。您的所有图书 — 隐藏和可见的 — 现在都会显示。再次下拉或离开应用即可退出隐藏模式。

🔒 隐私选项

当隐藏模式激活时，前往 设置 → 隐藏模式 选择离开应用时的行为：

  • 自动退出（默认）— 隐藏模式自动关闭。快捷简单。
  • 需要 Face ID / Touch ID — 隐藏模式保持开启，但返回时需要生物识别认证。更安全。

↩ 取消隐藏图书

在隐藏模式下，打开隐藏图书的详情并选择 取消隐藏，或使用选择模式批量取消隐藏。

☁ 同步隐藏图书

在隐藏模式下，前往 设置 → 隐藏模式，开启 将隐藏图书同步到 iCloud：

  • 关闭（默认）— 隐藏图书仅保留在此设备上。隐藏一本书也会将其从 iCloud 中移除。
  • 开启 — 隐藏图书会通过 iCloud 同步，但在您登录的每台设备上都保持隐藏。

当您在 iCloud 中已有隐藏图书时关闭此开关，系统会询问如何处理这些图书：

  • 在所有设备上保留 — 您的其他设备保留其同步副本；此设备保留一份仅限本地的私密副本。
  • 从 iCloud 完全移除 — 从 iCloud 中移除这些图书；其他每台设备都会在其隐藏书库中保留自己的私密副本。
注意：如果您的其他某台设备从 iCloud 中移除了一本隐藏图书，只要该书的文件此前已在此设备下载，此设备就会自动在隐藏书库中保留自己的私密副本。

🗑 永久删除隐藏图书

在隐藏模式下，前往 设置 → 隐藏模式，选择 永久删除隐藏图书，即可从此设备、iCloud 以及您的其他设备中移除所有隐藏图书。输入 DELETE 以确认。

警告：此操作无法撤销。当时处于离线状态的设备会保留其本地副本，直到下次同步。

书签、高亮 & 标签

🔖 书签

点击阅读器工具栏中的书签图标，为当前页添加书签。可添加备注。在图书详情页查看所有书签。

注意：这里只显示您手动创建的书签。应用在您关闭图书时自动保存的位置另行保存在阅读历史中，以免挤占您自己的书签。

🖍 高亮Premium

在 EPUB 中选中文本即可高亮。从五种颜色中选择（黄色、粉色、绿色、蓝色、橙色）并添加笔记。所有高亮都列在图书详情页上。

🏷 标签

从详情页为任何图书添加标签。标签可搜索，并可用作书库筛选条件。在 设置 → 标签 中管理所有标签。

阅读历史

快速回到您最近停留过的任意位置。

🕒 自动保存

每当您关闭一本书或将应用切换到后台，当前位置都会被保存为一条历史记录 — 无需记得手动添加书签。所有阅读器均支持：EPUB、PDF、TXT/RTF 和漫画。

  • 每本书最多保留 50 条最近的位置。新的位置加入时，较旧的记录会自动被移除。
  • 如果您在几分钟内在同一位置再次关闭这本书，则会更新现有记录，而不会创建重复项。
  • 自动保存的位置与您手动设置的书签列表分开保存，以免与您有意添加的书签混在一起。

📖 单本书内的历史

阅读时，点击右上角的更多菜单（…）并选择 阅读历史。您会看到该书中最近的位置列表，按最新优先排序，并显示对应的章节或页面名称以及每条记录的时间。

  • 点击任意条目即可直接跳到该位置。
  • 向左滑动条目可将其删除。

📚 整个书库的历史

在书库中，点击顶部工具栏的更多菜单（…）并选择 阅读历史，即可按日期分组查看您最近打开过的所有图书。点击某行即可从上次停下的位置打开该书。

iCloud 同步

在设备间保持书库同步。

☁ 启用同步

  1. 前往 设置 → iCloud 同步。
  2. 开启 将书库与 iCloud 同步。
  3. 同步将在下次启动应用时生效。

您的元数据、阅读进度、书签、高亮和书架会在登录同一 iCloud 账户的所有设备间同步。

📊 同步状态

设置 → iCloud 同步 会显示您图书文件的状态卡片：

  • 标题 — 已是最新、同步中…（附带数量）或 未登录。
  • 一条进度条，显示您书库中有多少文件已在 iCloud 中。
  • 明细 — 已同步（附带总大小）、仅在 iCloud（尚未下载到此设备）和 进行中。
注意：此卡片仅追踪图书文件。阅读进度、书签、高亮和书架会单独自动同步，与文件状态无关。

☁ 封面角标

图书封面右下角会显示一个小云朵图标，用于表示文件同步状态：

  • 云朵图标 — 文件仅存在于 iCloud。打开图书页面即可下载。
  • 上/下箭头 — 文件正在上传或下载。
  • 无图标 — 文件已在此设备上。

📥 自动下载

选择自动下载的最大文件大小。较大的图书将保留在云端，直到您打开它们。在 iCloud 设置中调整限制。

WebDAV & OPDS

从远程服务器和目录浏览并下载。

🗄 WebDAV

连接到 NAS、Nextcloud 或 Calibre 服务器来浏览文件夹并下载图书。

  1. 前往 设置 → 导入图书 → WebDAV。
  2. 点击 添加服务器 并输入 URL。
  3. 根据需要添加用户名和密码。
  4. 点击 测试连接，然后保存。
自签名证书：如果您的服务器使用自签名证书，可以开启 允许不受信任的证书。应用会先要求您确认 — 此操作会关闭 TLS 验证，因此同一网络上的任何人都可能冒充该服务器。请仅对您自己掌控的服务器启用。

📚 OPDS 目录

OPDS 是图书目录的开放标准。添加公共目录（Project Gutenberg、Standard Ebooks 等）或您自己的私有服务器。

  1. 前往 设置 → 导入图书 → OPDS。
  2. 点击 添加目录 并输入订阅源 URL。
  3. 浏览分类并将图书下载到书库。

启动时继续阅读

自动从上次停下的地方继续。

▶ 设置

前往 设置 → 通用，开启 启动时继续上次阅读的图书。下次打开应用时，将直接跳转到您上次阅读的图书和页面。

隐藏图书：如果您上次阅读的书是隐藏的，应用将在继续之前要求 Face ID / Touch ID 验证。在隐藏模式设置中启用 验证后继续隐藏图书 以允许此操作。
