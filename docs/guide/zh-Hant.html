匯入書籍

多種方式將書籍加入您的書庫。

📁 從「檔案」App

點選 設定 → 匯入書籍，然後從裝置、iCloud Drive 或任何已連接的雲端服務中選擇檔案。在 iPad 上還可以使用拖放操作。

🌐 WiFi 傳輸

從 WiFi 網路上的任何電腦或手機上傳書籍。詳情請參閱下方的專屬章節。

🗂 WebDAV & OPDS

連接到 NAS、Calibre 伺服器或公共書籍目錄，直接瀏覽和下載書籍。請參閱下方。

WiFi 傳輸

從本機網路上的任何裝置上傳書籍。

📶 運作方式

App 會在您的裝置上執行一個小型網頁伺服器。同一 WiFi 網路上的任何電腦或手機都可以在瀏覽器中開啟上傳頁面。

  1. 前往 設定 → 匯入書籍 → WiFi 傳輸。
  2. 點選 啟動伺服器，將顯示類似 http://192.168.1.42:8080 的位址。
  3. 在同一網路的任何瀏覽器中開啟該位址。
  4. 將檔案拖曳到頁面上或點擊瀏覽 — 按需選擇目標資料夾。
  5. 匯入的書籍會立即出現在您的書庫中。
  6. 完成後點選 停止伺服器。
提示：伺服器執行期間裝置將保持喚醒狀態，以免傳輸中斷。
上傳失敗？每個失敗的檔案會在所在列直接顯示原因。如果 WiFi 連線中斷，請點選該列中的 ↻ 重試 再次傳送。對於無法解決的問題（例如不支援的檔案格式），不會顯示重試按鈕。

書庫 & 整理

尋找、排序和整理您的書籍。

🔍 搜尋

點選書庫底部的搜尋膠囊按鈕以展開搜尋欄位，然後點選完成將其關閉。可按書名、作者、標籤、系列、出版社和描述進行搜尋。從書籍的操作選單依作者或標籤搜尋（參見依作者與標籤瀏覽）會帶入相同的搜尋內容。

↕ 排序 & 篩選

點選檢視選項按鈕（右上角）進行選擇：

  • 佈局 — 格狀、詳細、精簡、極簡、表格或雜誌
  • 排序 — 書名、作者、最近閱讀、加入日期、進度、檔案大小、系列
  • 顯示 — 將正在閱讀的書排在前面，已完成的排在最後
  • 篩選 — 按格式、標籤或作者

✔ 選擇模式

長按一本書或點選 選擇 進入選擇模式。然後可以一次移動、刪除、隱藏或取消隱藏多本書。

📋 清理重複項目

前往 設定 > 書庫 > 書庫維護 > 清理重複項目，尋找標題、作者和格式相同的書籍。對於每個重複群組：

  • 最新版本會標示綠色的 KEEP 徽章
  • 使用核取方塊選擇較舊的副本（或 全選）
  • 刪除 — 移除所選的較舊副本
  • 複製資料並刪除 — 在刪除之前將書籤、標示、標籤、閱讀進度和書架歸屬轉移到最新版本
  • 啟用 「將新書移動到舊書的書架與隱藏狀態」，以將新版本保留在書庫中的同一位置

閱讀書籍

EPUB、PDF、TXT 和 RTF 閱讀模式。

📖 EPUB

EPUB 檔案在全功能閱讀器中開啟。點選左右邊緣翻頁，或者滑動。

  • 分頁模式 — 傳統的逐頁閱讀，支援滑動、翻頁或無動畫。
  • 連續捲動Premium — 自然捲動閱讀文字，無分頁。
  • 閱讀方向 — 自動跟隨書籍設定，或自行設定為從左到右或從右到左。詳見閱讀方向。
  • 固定版面 — 漫畫、繪本及其他逐頁排版的 EPUB，會以專為其打造的閱讀器開啟。詳見固定版面書籍。
  • 書內搜尋Premium — 在整本書中搜尋任何字詞或片語。詳見書內搜尋。
  • 圖片庫Premium — 在書籍詳情頁瀏覽 EPUB 中的所有圖片。詳見圖片庫。
提示：在 設定 → 閱讀偏好 → 書籍 中調整字型大小、行距和主題顏色。

📄 PDF

PDF 檔案原生算繪。雙指縮放，滑動翻頁。App 可以記住受保護 PDF 的密碼。

📝 TXT & RTF

純文字和 RTF 檔案在簡單的文字閱讀器中開啟，可調整格式。

固定版面書籍

頁面採固定設計的 EPUB — 漫畫、繪本以及大量插圖的書籍。

📐 這是什麼

有些 EPUB 是逐頁排版，而非可重排的流動文字：每一頁都是文字與插圖的固定配置。App 會自動辨識這類書籍，並以專為其打造的閱讀器開啟 — 每一頁會縮放至符合螢幕並置中，周圍空間則以您的閱讀主題背景色填滿。

👋 閱讀與縮放

  • 點選螢幕左側或右側翻頁，或者滑動。點選中央可顯示或隱藏工具列。
  • 雙指縮放放大 — 最高可達符合大小的三倍 — 並拖曳以移動頁面。
  • 點兩下可放大該處；再點兩下則將頁面還原為符合螢幕大小。
  • 依從右到左方向出版的書籍會自動以該方向翻頁。

📖 雙頁跨頁

將裝置轉為橫向，對開頁會並排顯示。App 會遵循書籍內建的跨頁提示，因此封面或全頁插圖仍會單獨佔一頁。轉回直向即可恢復單頁顯示。

ℹ 可用功能

目錄、書籤、頁面滑桿、閱讀歷史，以及從上次停下之處繼續閱讀，這些功能都照常運作。

由於每一頁都是固定設計，而非 App 可重排的文字，這類書籍不會顯示部分控制項：連續捲動與自動捲動、字型與外觀設定、文字轉語音、書內搜尋，以及文字選取或標註。

書內搜尋

在正在閱讀的書中尋找任何字詞或片語。Premium

🔍 開始搜尋

  1. 點選頁面中央以顯示工具列。
  2. 點選底部工具列右端的放大鏡。
  3. 輸入至少兩個字元，然後按鍵盤上的 搜尋。

搜尋範圍是整本書 — 所有章節，而不只是螢幕上顯示的章節 — 且比對不區分大小寫。搜尋功能可在 EPUB 和 TXT/RTF 閱讀器中使用。

📄 瀏覽結果

結果會顯示在搜尋列下方，並依章節分組。每一列都會在一段前後文摘錄中以粗體顯示符合的內容。點選某個結果即可直接跳到該處 — 書中所有符合項目都會以黃色標示，目前的項目則以較深的琥珀色顯示。

↕ 在符合項目之間跳轉

選擇某個結果後，搜尋列會摺疊為精簡的長條，並附有計數器，顯示您目前位於第幾個符合項目。

  • 使用上下箭頭移至上一個或下一個符合項目。
  • 點選清單按鈕可重新開啟完整的結果清單。
  • 點選 × 結束搜尋 — 所有標示都會移除。

圖片庫

以可滑動的圖庫形式瀏覽 EPUB 中的每一幅插圖。Premium

🖼 開啟圖片庫

開啟某本 EPUB 書籍的詳情頁，點選右上角工具列中的照片堆疊按鈕 🖼。App 會從書中擷取所有圖片，處理期間會顯示進度列 — 點選左上角的 × 按鈕可隨時退出。圖片庫僅適用於 EPUB 書籍。

📚 您會看到的內容

圖片會依閱讀順序 — 即它們在書中各章節出現的順序 — 每頁顯示一張，並包含封面。圖示和裝飾等細小圖片會被略過：小於最小尺寸（預設為 100 px）的圖片不會顯示。可在 設定 → 閱讀偏好 → 書籍 → EPUB 圖庫 中調整此門檻。如果沒有符合條件的圖片，圖庫會告訴您未找到任何圖片。

👆 檢視與儲存圖片

  • 滑動即可在圖片之間切換，或使用底部的頁面滑桿快速跳轉。
  • 雙指縮放或點兩下即可放大，然後拖曳可四處移動 — 圖片庫使用與漫畫閱讀器相同的縮放方式。詳見漫畫頁面縮放。
  • 點選螢幕中央可顯示或隱藏控制項目。
  • 長按圖片可選擇 檢視完整解析度 — 以原始大小開啟該圖片以便仔細檢視 — 或選擇 儲存到「照片」、儲存到「檔案」或複製圖片。
  • 圖片庫會遵循您的漫畫閱讀方向 — 包括 Webtoon 式垂直捲動。

閱讀字型

選擇閱讀字型、加入自己的字型，或下載語言包。

🔤 選擇字型

開啟 設定 → 閱讀偏好 → 書籍 → 自訂字型 進入字型畫面。App 內建了多款閱讀字型，預設字型為 Literata。所選字型會套用至 EPUB 和文字閱讀器。

提示：在 設定 → 閱讀偏好 → 書籍 中調整字型大小和行距。

👓 無障礙字型

內建了兩款專為便於閱讀而設計、隨時可用的字型：Atkinson Hyperlegible 強化了相似字母之間的差異，OpenDyslexic 則加重了字母底部，以減少字母混淆。

📂 自訂字型

在字型畫面匯入您自己的 .ttf 或 .otf 字型檔案，即可在 EPUB 閱讀器中使用。匯入的字型僅保留在您的裝置上。

📥 下載字型和語言包

在下載字型中，可視需要取得 App 未隨附的文字系統所需的額外閱讀字型和語言包 — 中文、日文和韓文（CJK）、阿拉伯文、天城文和泰文。語言包體積較大（每個約 41 MB），因此下載前會顯示大小。安裝後，它們的使用方式與匯入的字型完全相同。

提示：如果書中的字元顯示為空白方框，請下載對應的語言包以顯示它們。

📜 字型授權

內建和可下載的字型均依據 SIL Open Font License 提供。您可以在字型畫面的每一列中閱讀相應字型的完整授權條款。

閱讀方向

從左到右、從右到左，或書籍出版時聲明的方向。

⇄ 選擇方向

開啟 設定 → 閱讀偏好 → 書籍，在閱讀模式下使用閱讀方向控制項：

  • 自動（預設）— 依書籍本身聲明的方向。漫畫及以從右到左方式出版的書籍，會自動以正確方向開啟，無需任何設定。
  • 從左到右 — 大多數西方書籍的標準方向。
  • 從右到左 — 讓所有書籍一律採用從右到左方向。

您也可以不離開書籍即可變更：點選頁面中央顯示工具列，然後點選底部工具列中的 Aa 按鈕。變更會立即套用到您目前正在閱讀的頁面。

👋 會隨方向改變的項目

  • 哪一側能讓您前進 — 在從右到左的書籍中，點選或向左滑動會翻到下一頁。
  • 翻頁動畫，會從正確的一側翻起。
  • 頁面上文字的排列方式。
注意：頁面滑桿一律從左側開始填滿，因為它顯示的是您在全書中的進度，而非頁面在螢幕上的位置。

ℹ 適用範圍

此設定僅適用於分頁模式的 EPUB — 開啟連續捲動時會隱藏此設定。漫畫有自己的閱讀順序設定（參見閱讀漫畫），而固定版面書籍一律遵循書籍聲明的方向。

直排書寫

以直排（縱式）排版的日文與中文書籍。

⬇ 直排書籍

以直排方式排版的書籍 — 日文稱為「縦書き」（たてがき），中文則稱為「直排」 — 會依照原始版面顯示：文字由上至下直書，欄位由右至左排列，翻頁方向與漫畫相同，同樣向左翻。

⚙ 書寫方向

開啟 設定 → 閱讀偏好 → 書籍，使用書寫方向控制項：

  • 自動（預設）— 依照每本書各自的版面配置。採直排編排的書籍會以直排顯示；其他書籍則不受影響。
  • 橫排 — 讓所有書籍都以橫排顯示，包括原本採直排編排的書籍。
  • 直排 — 讓所有書籍都以直排欄位顯示。

同樣的控制項也位於閱讀器內的設定中，在 Aa 按鈕底下。

注意：變更會在您下次開啟書籍時生效 — 目前畫面上的書籍會維持開啟時的版面配置。

ℹ 須知事項

  • 直排書籍一律使用分頁模式，因此無法使用連續捲動與自動捲動。
  • 直排書籍不會使用滑動效果換頁 — 而是改用翻頁效果。
  • 書籤、標註、目錄、書內搜尋和文字轉語音均可正常使用。

閱讀漫畫

CBZ、CBR 和 CB7 漫畫閱讀。

📱 閱讀模式

  • 由左至右 — 標準西方漫畫頁序。
  • 由右至左 — 日式漫畫閱讀順序。
  • Webtoon / 垂直捲動 — 適合長條漫畫的流暢垂直捲動。

在 設定 → 閱讀偏好 → 漫畫 中設定全域預設值，或在書籍詳情頁為單本書更改。

🔎 頁面縮放

  • 符合螢幕 — 顯示完整頁面。
  • 符合寬度 — 填滿寬度，需要時垂直捲動。
  • 符合高度 — 填滿高度。
  • 原始大小 — 1:1 像素顯示。

👋 手勢

  • 左右滑動翻頁（分頁模式）。
  • 雙指縮放或點兩下即可放大，然後拖曳可四處移動。詳見漫畫頁面縮放。
  • 點選頁面中央顯示或隱藏工具列。
  • 使用底部的頁面滑桿快速跳轉。

⚠ 可疑壓縮檔提示

當您開啟一個漫畫壓縮檔（CBZ、CBR 或 CB7），其內容看起來異常龐大或被過度壓縮 — 這正是“壓縮炸彈”檔案用來撐爆記憶體的典型特徵 — 應用程式會在解壓任何內容之前顯示可疑壓縮檔提示。

  • 點選 取消，不開啟該檔案。對於來源不明的壓縮檔，這是安全的選擇。
  • 如果您信任該檔案，可點選 仍然開啟 — 應用程式會略過安全檢查並載入頁面。

EPUB 檔案在匯入時會以相同方式默默使用該保護機制。

漫畫頁面縮放

不論是分頁模式或 Webtoon 捲動，都能讓您更貼近欣賞畫面細節。

🔍 分頁模式

  • 雙指縮放放大，最高可達符合大小的三倍；縮放時，畫面會跟隨您的手指移動。
  • 點兩下可將該處放大為兩倍大小；再點兩下可將頁面還原為符合螢幕大小。
  • 放大後可用單指拖曳，四處移動畫面。
  • 將手指幾乎完全捏合縮小時，頁面會自動貼齊符合螢幕的大小。

縮放適用於符合螢幕與符合高度縮放選項，也適用於雙頁跨頁畫面。符合寬度與原始大小本身就會以大於螢幕的尺寸顯示頁面並改用捲動方式瀏覽 — 這兩種模式請改用下方的檢視完整解析度來看得更清楚。

📱 Webtoon 捲動

  • 雙指縮放或點兩下可放大整條長圖，最高可達原始大小的三倍。
  • 放大時仍可正常捲動 — 只需照常上下拖曳即可。
  • 放大後左右拖曳即可橫向移動畫面。
  • 持續捲動時縮放比例會保持不變，讓您可以放大閱讀整個章節。旋轉裝置會將其還原為正常大小。

✨ 檢視完整解析度

縮放功能是以針對您螢幕準備好的尺寸來放大頁面。若想以最清晰的畫質檢視單一頁面，請長按該頁並選擇 檢視完整解析度 — 該頁會以壓縮檔中的原始解析度重新解碼，讓您可以再進一步放大更多。點兩下可在符合螢幕與兩倍大小之間切換；向下滑動或點選關閉按鈕即可返回。

注意：縮放不會被儲存。關閉書籍後一律會還原為正常的符合大小。

隱藏書籍

將某些書籍保持私密。Premium

👁 隱藏書籍

  1. 開啟書籍詳情頁並點選選單（…）。
  2. 選擇 隱藏書籍。
  3. 書籍將從正常的書庫檢視中消失。

要一次隱藏多本書，請使用選擇模式。

🔓 檢視隱藏書籍

在書庫中向下拉即可啟用 隱藏模式。您的所有書籍 — 隱藏和可見的 — 現在都會顯示。再次向下拉或離開 App 即可退出隱藏模式。

🔒 隱私選項

當隱藏模式啟用時，前往 設定 → 隱藏模式 選擇離開 App 時的行為：

  • 自動退出（預設）— 隱藏模式自動關閉。快速簡單。
  • 需要 Face ID / Touch ID — 隱藏模式保持開啟，但返回時需要生物辨識驗證。更安全。

↩ 取消隱藏書籍

在隱藏模式下，開啟隱藏書籍的詳情並選擇 取消隱藏，或使用選擇模式批次取消隱藏。

☁ 同步隱藏書籍

在隱藏模式下，前往 設定 → 隱藏模式，開啟 將隱藏書籍同步到 iCloud：

  • 關閉（預設）— 隱藏書籍僅保留在此裝置上。隱藏一本書也會將其從 iCloud 中移除。
  • 開啟 — 隱藏書籍會透過 iCloud 同步，但在您登入的每台裝置上都會保持隱藏。

當您在 iCloud 中已有隱藏書籍時關閉此開關，系統會詢問要如何處理這些書籍：

  • 在所有裝置上保留 — 您的其他裝置會保留其同步副本；此裝置會保留一份僅限本機的私密副本。
  • 從 iCloud 完全移除 — 從 iCloud 中移除這些書籍；其他每台裝置都會在其隱藏書庫中保留自己的私密副本。
注意：如果您的其他某台裝置從 iCloud 移除了一本隱藏書籍，只要該書的檔案先前已在此裝置下載，此裝置就會自動在隱藏書庫中保留自己的私密副本。

🗑 永久刪除隱藏書籍

在隱藏模式下，前往 設定 → 隱藏模式，選擇 永久刪除隱藏書籍，即可從此裝置、iCloud 以及您的其他裝置中移除所有隱藏書籍。輸入 DELETE 以確認。

警告：此操作無法復原。當下處於離線狀態的裝置會保留其本機副本，直到下次同步。

閱讀歷史

快速回到您最近停留過的任意位置。

🕒 自動儲存

每當您關閉一本書或將應用程式切換到背景，目前位置都會被儲存為一筆歷史紀錄 — 無需記得手動加入書籤。所有閱讀器均支援：EPUB、PDF、TXT/RTF 和漫畫。

  • 每本書最多保留 50 筆最近的位置。新的位置加入時，較舊的紀錄會自動被移除。

  • 點選任一項目即可直接跳到該位置。
  • 向左滑動項目即可將其刪除。

WebDAV & OPDS

從遠端伺服器和目錄瀏覽並下載。

🗄 WebDAV

連接到 NAS、Nextcloud 或 Calibre 伺服器來瀏覽資料夾並下載書籍。

  2. 點選 新增目錄 並輸入訂閱來源 URL。
