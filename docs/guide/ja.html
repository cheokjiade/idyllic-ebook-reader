本のインポート

ライブラリに本を追加するいくつかの方法。

📁 ファイルアプリから

設定 → 本をインポートをタップし、デバイス、iCloud Drive、または接続済みのクラウドサービスからファイルを選択してください。iPadではドラッグ＆ドロップも使えます。

NAS、Calibreサーバー、または公開ブックカタログに接続して、直接閲覧およびダウンロードできます。下記をご覧ください。

WiFi転送

ローカルネットワーク上のどのデバイスからでも本をアップロードできます。

📶 仕組み

アプリはデバイス上で小さなウェブサーバーを起動します。同じWiFiネットワーク上のどのパソコンやスマートフォンからでも、ブラウザでアップロードページを開けます。

  1. 設定 → 本をインポート → WiFi転送に進みます。
  2. サーバーを開始をタップします。http://192.168.1.42:8080のようなアドレスが表示されます。
  3. 同じネットワーク上のウェブブラウザでそのアドレスを開きます。
  4. ファイルをページにドラッグするか、クリックして選択します。必要に応じて保存先フォルダを選べます。
  5. インポートされた本はすぐにライブラリに表示されます。
  6. 完了したらサーバーを停止をタップします。
ヒント：サーバーが動作中はデバイスがスリープしないため、転送が中断されません。
アップロードに失敗しましたか？失敗した各ファイルにはその行に理由が表示されます。WiFi接続が切れた場合は、行の↻ 再試行をタップするともう一度送信できます。サポートされていないファイル形式など、恒久的な問題の場合は再試行ボタンは表示されません。

ライブラリと整理

本を検索、並べ替え、整理できます。

🔍 検索

ライブラリ下部のSearchピルをタップして検索フィールドを開き、完了をタップして閉じます。タイトル、著者、タグ、シリーズ、出版社、説明を横断的に検索します。本のコンテキストメニューから著者やタグで検索すると（著者・タグ別に閲覧を参照）、同じ検索欄が入力されます。

↕ 並べ替えとフィルター

表示オプションボタン（右上）をタップして選択：

  • レイアウト — グリッド、詳細、コンパクト、ミニマリスト、テーブル、マガジン
  • 並べ替え — タイトル、著者、最終読書日、追加日、進捗、ファイルサイズ、シリーズ
  • 表示 — 読書中の本を先頭に、読了済みの本を末尾に配置
  • フィルター — フォーマット、タグ、著者、シリーズ、または評価で絞り込み

📚 シリーズ

表示オプションのレイアウトでシリーズでグループ化をオンにすると、表示中のフォルダ内で2冊以上あるシリーズが、表紙・シリーズ名・読了した冊数を示す1つのスタックにまとまります。スタックをタップするとシリーズ画面が開きます。読む順に並んだ本と、シリーズが複数のフォルダに分かれている場合はどのフォルダにあるかを示す行が表示されます。シリーズ情報のある本を長押ししてシリーズを表示を選ぶと同じ画面が開きます。テーブルとマガジンのレイアウトではシリーズでグループ化は使用できません。

ライブラリ内のすべてのシリーズを一度に見るには、…メニューを開いてすべてのシリーズを選びます。シリーズ画面のメニューから順序を編集、シリーズ名を変更…、シリーズ設定…の変更ができます。

✔ 選択モード

本を長押しするか、選択をタップして選択モードに入ります。複数の本をまとめて移動、削除、非表示、または再表示できます。

📋 重複を整理

設定 > ライブラリ > ライブラリのメンテナンス > 重複を整理 に移動すると、タイトル・著者・形式が同じ本を検索できます。各重複グループでは：

  • 最新バージョンには緑の KEEP バッジが付きます
  • チェックボックスで古いコピーを選択します（または すべて選択）
  • 削除 — 選択した古いコピーを削除します
  • データをコピーして削除 — ブックマーク、ハイライト、タグ、読書の進捗、棚の割り当てを最新バージョンに引き継いでから削除します
  • 「新しい本を古い本の棚と非表示状態に移動」を有効にすると、新しいバージョンを同じライブラリ内の場所に保持できます

本を読む

EPUB、PDF、TXT、RTFの閲覧モード。

📖 EPUB

EPUBは高機能リーダーで開きます。左右の端をタップするか、スワイプしてページをめくれます。

  • ページめくり — スライド、めくり、またはアニメーションなしの従来のページ送り形式での閲覧。
  • 連続スクロールPremium — テキストを自然にスクロールでき、ページ区切りがありません。
  • 読み方向 — 本の指定に自動的に従うか、左から右・右から左を自分で設定できます。詳しくは読み方向をご覧ください。
  • 固定レイアウト — マンガや絵本など、ページ単位で構成されたEPUBは専用のリーダーで開きます。詳しくは固定レイアウトの本をご覧ください。
  • 本文内検索Premium — 本全体から任意の語句を検索できます。詳しくは本文内検索をご覧ください。
  • 画像ギャラリーPremium — 本の詳細ページからEPUB内のすべての画像を閲覧できます。詳しくは画像ギャラリーをご覧ください。
ヒント：フォントサイズ、行間、テーマカラーは設定 → 読書設定 → 本で調整できます。

📄 PDF

PDFはネイティブで表示されます。ピンチでズーム、スワイプでページめくりができます。パスワード保護されたPDFのパスワードを記憶できます。

📝 TXTとRTF

テキストファイルとRTFファイルは、書式を調整できるシンプルなテキストリーダーで開きます。

固定レイアウトの本

ページが固定デザインになっているEPUB — マンガ、絵本、挿絵の多い本など。

📐 固定レイアウトとは

一部のEPUBは、流れるテキストではなくページ単位でレイアウトされています。各ページは文字とイラストが固定配置されたデザインです。アプリはこうした本を自動的に認識し、それ専用のリーダーで開きます — 各ページは画面に合わせて拡大縮小され中央に配置され、余白は読書テーマの背景色で塗りつぶされます。

👋 読み方とズーム

  • 画面の左右をタップするか、スワイプしてページをめくります。中央をタップするとツールバーの表示・非表示が切り替わります。
  • ピンチでズームイン — 最大でフィットサイズの3倍まで — し、ドラッグしてページ内を移動できます。
  • ダブルタップでその位置を拡大します。もう一度ダブルタップすると画面に合わせて戻ります。
  • 右から左に読むよう出版された本は、自動的にその向きでページがめくられます。

📖 見開き表示

デバイスを横向きにすると、向かい合うページが並んで表示されます。アプリは本自体に含まれる見開きのヒントに従うため、表紙やページ全面のイラストにも単独のページが割り当てられます。縦向きに戻すと1ページずつの表示に戻ります。

ℹ 利用できる機能

目次、ブックマーク、進捗スライダー、読書履歴、続きから再開はすべて通常どおり動作します。

各ページはアプリが再構成できるテキストではなく固定デザインのため、これらの本では一部の機能が表示されません — 連続スクロールと自動スクロール、フォントと外観の設定、テキスト読み上げ、本文内検索、テキストの選択やハイライトです。

本文内検索

読んでいる本の中から任意の語句を見つけられます。Premium

🔍 検索を始める

  1. ページ中央をタップしてツールバーを表示します。
  2. 下部バーの右端にある虫眼鏡をタップします。
  3. 2文字以上入力し、キーボードの検索を押します。

検索対象は本全体です — 画面に表示中の章だけでなく、すべての章が検索されます — また、大文字と小文字は区別されません。検索はEPUBとTXT/RTFのリーダーで利用できます。

📄 検索結果を見る

結果は検索バーの下に章ごとにまとめて表示されます。各行には、前後の文脈の抜粋の中に一致箇所が太字で表示されます。結果をタップするとその位置に直接ジャンプします — 本文中のすべての一致箇所が黄色でハイライトされ、現在の一致箇所はより濃いアンバー色で表示されます。

↕ 一致箇所間の移動

結果を選ぶと、検索バーはコンパクトな帯に折りたたまれ、現在何番目の一致箇所にいるかを示すカウンターが表示されます。

  • 上下の矢印で前後の一致箇所に移動できます。
  • リストボタンをタップすると結果一覧を再表示できます。
  • ×をタップすると検索を終了し、すべてのハイライトが解除されます。

画像ギャラリー

EPUB内のすべての挿絵をスワイプで閲覧できるギャラリー。Premium

🖼 ギャラリーを開く

EPUBの本の詳細ページを開き、右上のツールバーにある写真スタックボタン🖼をタップします。アプリが本からすべての画像を抽出し、処理中は進行状況バーが表示されます — 左上の×ボタンでいつでも中断して戻れます。ギャラリーはEPUBの本でのみ利用できます。

📚 表示される内容

画像は読書順 — 本の章に登場する順序 — に1ページ1枚で表示され、表紙も含まれます。アイコンや装飾などの小さな画像はスキップされます。最小サイズ（既定では100 px）より小さいものは除外されます。しきい値は設定 → 読書設定 → 本 → EPUBギャラリーで調整できます。条件を満たす画像がない場合は、画像が見つからなかったことが表示されます。

👆 画像の表示と保存

  • スワイプで画像を切り替えるか、下部のページスライダーですばやくジャンプできます。
  • ピンチまたはダブルタップでズームし、ドラッグして移動できます — ギャラリーはコミックリーダーを使用しているため、ズームの操作方法もまったく同じです。詳しくはコミックページのズームをご覧ください。
  • 画面中央をタップするとコントロールの表示・非表示が切り替わります。
  • 画像を長押しするとフル解像度で表示を選べます — 元のサイズで細部までじっくり確認できます — ほかに"写真"に保存、"ファイル"に保存、画像をコピーもできます。
  • ギャラリーはコミックの読み進める方向に従います — Webtoon形式の縦スクロールにも対応します。

読書フォント

読書用のフォントを選んだり、自分のフォントを追加したり、言語パックをダウンロードできます。

🔤 フォントを選ぶ

設定 → 読書設定 → 本 → カスタムフォントを開くとフォント画面が表示されます。いくつかの読書用フォントが標準で搭載されており、Literataが既定のフォントです。選んだフォントはEPUBリーダーとテキストリーダーに適用されます。

ヒント：フォントサイズと行間は設定 → 読書設定 → 本で調整できます。

👓 アクセシビリティフォント

読みやすさを重視して設計された2つのフォントが標準で搭載されており、いつでも利用できます。似た文字の違いをはっきりさせるAtkinson Hyperlegibleと、文字の取り違えを減らすよう下部を重くしたOpenDyslexicです。

📂 カスタムフォント

フォント画面から自分の.ttfまたは.otfフォントファイルを読み込んで、EPUBリーダーで使用できます。読み込んだフォントはデバイス内にとどまります。

📥 フォントと言語パックのダウンロード

フォントをダウンロードでは、アプリに同梱されていない文字体系向けに、追加の読書用フォントや言語パックを必要に応じて入手できます — 中国語、日本語、韓国語（CJK）、アラビア語、デーバナーガリー、タイ語です。パックは容量が大きい（それぞれ約41 MB）ため、ダウンロード前にサイズが表示されます。インストールすると、読み込んだフォントとまったく同じように使えます。

ヒント：本の文字が空の四角として表示される場合は、対応する言語パックをダウンロードすると表示できます。

📜 フォントライセンス

同梱およびダウンロード可能なフォントはSIL Open Font Licenseのもとで提供されています。フォント画面の各行から、それぞれの全文ライセンスを読むことができます。

読み方向

左から右、右から左、または本が出版された向きにそのまま従います。

⇄ 方向を選ぶ

設定 → 読書設定 → 本を開き、読書モード内の読み方向コントロールを使用します。

  • 自動（既定）— 本自体が指定する方向に従います。マンガや右から左に読むよう出版された本は、設定なしで正しい向きに開きます。
  • 左から右 — ほとんどの欧米書籍で標準的な方向です。
  • 右から左 — すべての本を右から左で表示します。

本を開いたまま変更することもできます — ページ中央をタップしてツールバーを表示し、下部バーのAaボタンをタップします。変更は今読んでいるページにすぐ反映されます。

👋 読み方向が影響する範囲

  • どちら側をタップ・スワイプすると先に進むか — 右から左の本では、左方向へのタップやスワイプが次のページに進みます。
  • ページめくりのアニメーション。正しい側からめくれます。
  • ページ内のテキストのレイアウト。
注意：進捗スライダーは常に左から埋まります。本の中でどれだけ進んだかを示すもので、ページが画面上のどちら側にあるかを示すものではないためです。

ℹ 適用される範囲

この設定はページめくりモードのEPUB向けです — 連続スクロールがオンのときは表示されません。コミックには独自の読み順設定があります（コミックを読むを参照）。また固定レイアウトの本は、常に本の中で指定された方向に従います。

縦書き

日本語や中国語の本を縦組みで表示します。

⬇ 縦組みの本

縦組みで組版された本 — 日本語の縦書きや中国語の直排 — は、組まれたとおりに表示されます。テキストは上から下へ、行は右から左へ並び、マンガと同じように左方向へページがめくれます。

⚙ 組方向

設定 → 読書設定 → 本を開き、組方向コントロールを使用します。

  • 自動（既定）— 各本自体のレイアウトに従います。縦組みで組版された本は縦書きで表示され、それ以外の本には影響しません。
  • 横書き — 縦組みの本を含め、すべての本を横書きで表示します。
  • 縦書き — すべての本を縦書きの段組みで表示します。

同じコントロールはリーダー内設定のAaボタンからも利用できます。

注意：変更は次に本を開いたときに適用されます — 表示中の本は開いたときのレイアウトのまま変わりません。

ℹ 知っておきたいこと

  • 縦書きの本は常にページめくりモードを使用するため、連続スクロールと自動スクロールは利用できません。
  • 縦書きの本にはスライドのページアニメーションは使われません — 代わりにめくるアニメーションでめくられます。
  • ブックマーク、ハイライト、目次、本文内検索、テキスト読み上げはすべて通常どおり動作します。

コミックを読む

CBZ、CBR、CB7のコミック閲覧。

📱 閲覧モード

  • 左から右 — 標準的な欧米コミックのページ順。
  • 右から左 — マンガの読み順。
  • Webtoon / 縦スクロール — 縦長コミック向けのスムーズな縦スクロール。

設定 → 読書設定 → コミックでグローバルデフォルトを設定するか、各本の詳細ページから個別に変更できます。

🔎 ページスケーリング

  • 画面にフィット — ページ全体が表示されます。
  • 幅にフィット — 幅いっぱいに表示し、必要に応じて縦スクロールします。
  • 高さにフィット — 高さいっぱいに表示します。
  • オリジナルサイズ — 1:1ピクセル表示。

👋 ジェスチャー

  • 左右にスワイプしてページをめくります（ページ送りモード）。
  • ピンチまたはダブルタップでズームし、ドラッグして移動できます。詳しくはコミックページのズームをご覧ください。
  • ページ中央をタップするとツールバーの表示・非表示が切り替わります。
  • 下部のページスライダーですばやくジャンプできます。

⚠ 不審なアーカイブの警告

コミックアーカイブ（CBZ、CBR、CB7）を開いたとき、その内容が異常に大きい、または極端に圧縮されている — メモリを圧迫するように設計された「zip bomb」ファイルに見られるパターン — 場合、アプリは展開する前に不審なアーカイブのアラートを表示します。

  • キャンセルをタップするとファイルは開かれません。出所が不明なアーカイブには、こちらが安全な選択です。
  • ファイルを信頼できる場合はそのまま開くをタップしてください — アプリは安全チェックをスキップしてページを読み込みます。

EPUBファイルもインポート時に同じ保護機能を内部的に使用しています。

コミックページのズーム

ページ表示モードでもWebtoonスクロールでも、アートワークをもっと近くで見られます。

🔍 ページ表示モード

  • ピンチでズームイン — 最大でフィットサイズの3倍まで。ピンチしている指の下にアートワークが追従します。
  • ダブルタップでその位置を2倍サイズにジャンプします。もう一度ダブルタップすると画面に合わせて戻ります。
  • ズーム中は1本指でドラッグして移動できます。
  • ほぼ元のサイズまでピンチで戻すと、ページはきれいにフィットサイズへスナップします。

ズームは画面にフィットと高さにフィットのスケーリングオプション、および見開き表示で使用できます。幅にフィットとオリジナルサイズはすでに画面より大きくページを表示してスクロールする形式のため、こちらではより近くで見るために下記のフル解像度で表示を使用してください。

📱 Webtoonスクロール

  • ピンチまたはダブルタップでストリップ全体をズームします — 最大で通常サイズの3倍まで。
  • ズーム中もスクロールは通常どおり続けられます — そのまま上下にドラッグするだけです。
  • 横方向にドラッグすると、ズームしたページ内を移動できます。
  • スクロールを続けてもズームレベルは維持されるため、章全体を拡大したまま読み進められます。デバイスを回転すると通常サイズに戻ります。

✨ フル解像度で表示

ズームは画面用に用意されたサイズでページを拡大します。1ページを最も鮮明に見たい場合は、そのページを長押ししてフル解像度で表示を選んでください — そのページはアーカイブの元の解像度でデコードされ、さらに大きくピンチインできます。ダブルタップで画面にフィットと2倍サイズを切り替えられます。下にスワイプするか閉じるボタンをタップすると元に戻ります。

注意：ズームは保存されません。本を閉じると常に通常のフィット表示に戻ります。

テキスト読み上げとCarPlay

本を音声で聞きましょう。

🔊 テキスト読み上げの使い方

EPUB、PDF、またはTXTの本を開き、ツールバーの再生ボタンをタップします。TTSは一文ずつ読み上げ、現在の単語をハイライト表示します。

  • 速度 — TTSコントロールで0.5倍から2倍まで。
  • 音声 — 設定 → 読書設定 → テキスト読み上げで100以上のシステム音声から選択。
  • スキップ — 次/前をタップして文単位またはチャプター単位でジャンプ。
注意：固定レイアウトの本 — ページが固定デザインになっているマンガや絵本 — には読み上げるテキストがないため、これらの本では再生ボタンが表示されません。

🚗 CarPlay

CarPlay対応車両に接続すると、シンプルな再生コントロールで車のディスプレイにアプリが表示されます。TTSはバックグラウンドで再生を続けるため、画面をオンにしておく必要はありません。

ヒント：TTS設定でバックグラウンドオーディオPremiumを有効にすると、CarPlayなしでもアプリがバックグラウンドにあるときに再生を続けられます。

AIコミックアップスケーリング

デバイス上で低解像度のコミックページを高画質化します。Premium

✨ 機能説明

デバイス上の機械学習モデルを使用して、解像度のしきい値を下回るコミックページをアップスケールします。より鮮明な線と圧縮アーティファクトの軽減が得られ、古いスキャンや低品質のスキャンに特に有効です。

⚙ セットアップ

  1. 設定 → 読書設定 → コミック → AIアップスケーリングに進みます。
  2. オンにします。
  3. 解像度しきい値を調整します。このピクセル幅以下のページがアップスケールされます（デフォルト：1500 px）。
  4. プリフェッチウィンドウを設定して、バックグラウンドで事前処理する先読みページ数を制御します。
  5. ノイズ除去レベルを選択します（自動が最適な場合がほとんどです）。

💾 キャッシュとストレージ

アップスケール済みの画像はキャッシュされるため、再処理の必要がありません。キャッシュの保持期間（7〜90日または無期限）を選び、設定からいつでもクリアできます。

ヒント：アップスケールされたページには小さなインジケーターバッジが表示されます。不要な場合は設定でオフにできます。

非表示の本

特定の本をプライベートに保ちます。Premium

👁 本を非表示にする

  1. 本の詳細ページを開き、メニュー（…）をタップします。
  2. 本を非表示を選択します。
  3. 本が通常のライブラリ表示から消えます。

複数の本を一括で非表示にするには、選択モードを使用してください。

🔓 非表示の本を見る

ライブラリを下にスクロールすると非表示モードが有効になります。すべての本（非表示と表示の両方）が表示されます。もう一度スクロールするか、アプリを閉じると非表示モードが解除されます。

🔒 プライバシーオプション

非表示モードが有効な場合、設定 → 非表示モードでアプリを離れたときの動作を選択できます：

  • 自動終了（デフォルト） — 非表示モードが自動的にオフになります。シンプルで手軽です。
  • Face ID / Touch IDを要求 — 非表示モードはオンのままですが、再開時に生体認証が必要です。より安全です。

↩ 本の再表示

非表示モード中に、非表示の本の詳細を開いて本を再表示を選択するか、選択モードで一括再表示できます。

☁ 非表示の本を同期

非表示モードで設定 → 非表示モードに進み、非表示の本をiCloudと同期を切り替えます：

  • オフ（デフォルト） — 非表示の本はこのデバイスにのみ保存されます。本を非表示にすると、iCloudからも削除されます。
  • オン — 非表示の本はiCloud経由で同期されますが、サインインしているすべてのデバイスで非表示のままです。

すでにiCloudに非表示の本がある状態でこの切り替えをオフにすると、それらをどうするか確認されます：

  • すべてのデバイスに残す — 他のデバイスは同期されたコピーを保持し、このデバイスはローカルのみのプライベートコピーを保持します。
  • iCloudから完全に削除 — iCloudから本を削除します。他の各デバイスは、非表示ライブラリに独自のプライベートコピーを保持します。
注意：他のデバイスがiCloudから非表示の本を削除した場合、その本のファイルがすでにダウンロード済みであれば、このデバイスは非表示ライブラリに自動的に独自のプライベートコピーを保持します。

🗑 非表示の本を完全に削除

非表示モードで設定 → 非表示モードに進み、非表示の本を完全に削除を選択すると、すべての非表示の本がこのデバイス、iCloud、他のデバイスから削除されます。確認のためDELETEと入力してください。

警告：この操作は取り消せません。その時点でオフラインのデバイスは、次回同期するまでローカルコピーを保持します。

読書履歴

最近開いていた位置にすぐに戻れます。

🕒 自動保存

本を閉じたり、アプリをバックグラウンドに移動したりするたびに、現在の位置が履歴エントリーとして保存されます — ブックマークを付けるのを覚えておく必要はありません。EPUB、PDF、TXT/RTF、コミックなど、すべてのリーダーで動作します。

  • 本ごとに最新の50件の位置が保持されます。新しいエントリーが追加されると、古いものは自動的に削除されます。
  • 数分以内に同じ場所で本を再度閉じた場合、重複を作成する代わりに既存のエントリーが更新されます。
  • 自動保存された位置は、手動で意図的に設定したブックマークと混ざらないように、手動ブックマークのリストとは分けて保管されます。

📖 本の中の履歴

読書中に右上のオーバーフローメニュー（…）をタップし、読書履歴を選択します。その本における最近の位置が新しい順にリスト表示され、章またはページ名と、各エントリーが記録されてからの時間が表示されます。

  • 任意のエントリーをタップするとその位置に直接ジャンプします。
  • エントリーを左にスワイプすると削除できます。

📚 ライブラリ全体の履歴

ライブラリで上部ツールバーのオーバーフローメニュー（…）をタップし、読書履歴を選択すると、最近開いたすべての本が日付ごとにグループ化されて表示されます。行をタップすると、前回中断した場所から本を開けます。

iCloud同期

デバイス間でライブラリを同期します。

☁ 同期の有効化

  1. 設定 → iCloud同期に進みます。
  2. ライブラリをiCloudと同期をオンにします。
  3. 同期は次のアプリ起動時に反映されます。

メタデータ、読書の進捗、ブックマーク、ハイライト、シェルフが同じiCloudアカウントにサインインしたすべてのデバイス間で同期されます。

📊 同期ステータス

設定 → iCloud同期で、本のファイルのステータスカードが表示されます：

  • 見出し — 最新、同期中…（件数付き）、またはサインインしていません。
  • ライブラリのファイルのうちどれだけがiCloudにあるかを示すバー。
  • 内訳 — 同期済み（合計サイズ付き）、iCloudのみ（このデバイスにまだダウンロードされていない）、処理中。
注意：このカードは本のファイルのみを追跡します。読書の進捗、ブックマーク、ハイライト、シェルフはファイルの状態に関係なく、別途自動的に同期されます。

☁ 表紙バッジ

本の表紙の右下に、ファイルの同期状態を示す小さな雲のアイコンが表示されます：

  • 雲のアイコン — ファイルはiCloudにのみ存在します。本のページを開いてダウンロードしてください。
  • 上下の矢印 — ファイルは現在アップロードまたはダウンロード中です。
  • アイコンなし — ファイルはすでにこのデバイスにあります。

📥 自動ダウンロード

自動ダウンロードの最大ファイルサイズを選択します。それより大きな本は開くまでクラウドに保持されます。iCloud設定で上限を調整できます。

WebDAVとOPDS

リモートサーバーやカタログから閲覧・ダウンロードできます。

🗄 WebDAV

NAS、Nextcloud、またはCalibreサーバーに接続してフォルダを閲覧し、本をダウンロードします。

  1. 設定 → 本をインポート → WebDAVに進みます。

  3. 必要に応じてユーザー名とパスワードを追加します。

自己署名証明書：サーバーが自己署名証明書を使用している場合は信頼されていない証明書を許可をオンにできます。アプリはまず確認を求めます — これはTLS検証を無効にするため、同じネットワーク上の第三者がサーバーになりすます恐れがあります。自分が管理するサーバーに対してのみ有効にしてください。

📚 OPDSカタログ

OPDSはブックカタログのオープンスタンダードです。公開カタログ（Project Gutenberg、Standard Ebooksなど）またはプライベートサーバーを追加できます。

  1. 設定 → 本をインポート → OPDSに進みます。
  2. カタログを追加をタップし、フィードURLを入力します。
  3. カテゴリを閲覧し、ライブラリに本をダウンロードします。
